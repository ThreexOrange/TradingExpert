## 核查结果

- **最具体的交易自述**是 2022-01-30 的 BTC 在 37,853 开空，另有 2020 年两帖写到在 9,269 与 9,288 提前布局。公开更新缺少成交数量、费用以及对应的逐笔平仓。莲花控股有同花顺 B/S 图与「翻倍出本」自述。要确认年年翻倍，仍需连续账户权益与资金进出记录。[BTC 开空原帖](https://cn.tradingview.com/chart/XBTUSD.P/Xk2YETqI/) · [莲花控股原帖](https://guba.eastmoney.com/news,600186,1731834732.html)
- **公开指标**共有 8 个，分型波段开源，其余 7 个仅限邀请，公开页仍有说明与图表。GitHub 项目当前文件和公开提交历史只有文档和图像。公开说明里，黄色闪光与主力识别相关。[TradingView 脚本主页](https://cn.tradingview.com/u/eggwong/#published-scripts) · [GitHub 仓库](https://github.com/eggwong2/LWAI-trade) · [维护者的公开回复](https://github.com/eggwong2/LWAI-trade/issues/2#issuecomment-6169885690)
- **账号之间的关联**。用户确认 TradingView 账号为 eggwong。该账号的《众泰汽车10倍交易计划》署名《老王看交易》，其较新的公开指标使用 LWAI 品牌。东方财富同名账号发布的研报也带 LWAI 标识，两图嵌有同花顺同名账号。GitHub 维护者在项目中使用 LWAI 和老王称呼。这些公开线索相互印证。[TradingView 署名帖](https://cn.tradingview.com/chart/000980/A2LoeQSw/) · [东方财富主页](https://i.eastmoney.com/8601326172918334) · [GitHub README](https://github.com/eggwong2/LWAI-trade#readme)
