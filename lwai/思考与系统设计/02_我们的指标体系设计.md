# 我们的指标体系设计

目标：借鉴老王「主力行为周期 + 多层确认」的骨架，做一套**我们自己定义、能被检验**的指标系统。每个模块写清公式、默认参数和「无未来函数」的处理，可以直接交给人或 AI 写成 Pine Script / Python。

所有默认参数都是**初值**，标注来源（借鉴老王公开参数 / 经典文献 / 我们的推导），必须经过 [03 号文档](03_%E9%AA%8C%E8%AF%81%E6%96%B9%E6%B3%95%E4%B8%8E%E6%94%B6%E7%9B%8A%E9%A2%84%E6%9C%9F.md) 的流程验证后才能定稿。

## 总体结构

```
┌──────────────────────────── 0. 环境闸门（大盘/情绪/刹车）────────────────────────────┐
│                                                                                   │
│  A. 股票池扫描 ─▶ B. 衰减筹码      ─┐                                              │
│   (每日排序)      C. HVN 簇状态机  ─┼─▶ H. 个股状态机 ─▶ G. 执行与退出（仓位/止损/出本）│
│                  D. 资金身份分    ─┤   （三族确认）                                  │
│                  E. 实体谱雷达    ─┤                                               │
│                  F. 破底站稳触发  ─┘                                               │
└───────────────────────────────────────────────────────────────────────────────────┘
```

**三族独立确认**是整个系统的核心约束。信号来自三类不同的信息：

| 信号族 | 模块 | 信息来源 |
|---|---|---|
| 结构族「钱堆在哪」 | B、C、F | 价格 × 成交量在价格轴上的分布 |
| 资金族「谁在动」 | D | 主动买卖方向（Delta）与量能节奏 |
| 时频族「有没有方向」 | E | K 线实体序列的频谱结构 |

入场要求至少两族同时同意，且其中一族必须是触发（F 或 C 的 Spring 或 E 的起爆）。MACD、RSI、KDJ 这类同源动量指标再多也只算一票，不能叠加「共振」，这是老王「指标共振」容易犯的错。

## 数据降级链（所有模块共用）

订单流是老王新工具的核心，但真实逐笔数据贵、历史短。我们统一用一个**Delta 估算器**，按可得性自动降级，并在面板上显示当前用的是哪一级：

| 级别 | 数据 | 主动买量 buy 的算法 |
|---|---|---|
| L1 真实 | TradingView Footprint（Premium）/ Level-2 逐笔 | 交易所给出的主动买成交量 |
| L2 小周期 | 1 分钟或 5 分钟 K 线 | 每根小 K：`buy_i = V_i × (C_i − L_i)/(H_i − L_i)`，求和到日线 |
| L3 日线 | 只有日 OHLCV | `buy = V × CLV⁺`，`CLV⁺ = (C − L)/(H − L)` |
| 一字板 | H = L | 涨：buy = V；跌：buy = 0；平：各半 |

`Delta = buy − (V − buy) = V × (2·CLV⁺ − 1)`，`Delta% = Delta / V`。

> L2 用 CLV 拆分而不是老王的「阳线全买、阴线全卖」，因为后者在小 K 线十字星多时偏差大。两者都是近似，L3 的误差最大。回测时必须用和实盘相同级别的数据，不能用 L1 回测、L3 实盘。

**收盘位置**（老王自选列之一）用含昨收的区间：`CL = (C − min(L, C₋₁)) / (max(H, C₋₁) − min(L, C₋₁))`，一字涨停 = 1、一字跌停 = 0。

## 模块 0：环境闸门

决定**能不能开新仓、开多大**，不决定买哪只。

| 项 | 定义 | 默认 |
|---|---|---|
| 指数趋势 | 基准指数收盘相对 MA200 | 小盘策略用中证 1000 或中证 2000，大盘股用沪深 300 |
| 情绪宽度 | 全 A 收盘在 MA20 上方的比例 `Breadth20` | — |
| 赚钱效应 | 近 5 日涨停家数 / (涨停 + 跌停) | — |
| 刹车 | 指数 < MA200 **且** ATR14 > 1.5 × ATR14 的 100 日中位数 **且** 指数收盘 < 5 日前（借鉴老王 MMOF⑤） | 触发即停止开新仓 |

仓位系数 `g ∈ {0, 0.5, 1}`，乘到模块 G 的单笔风险上。刹车（崩盘进行中）→ 0。

> **日线原型的反直觉结果**（[结果](code/%E7%BB%93%E6%9E%9C_%E6%97%A5%E7%BA%BF%E5%8E%9F%E5%9E%8B_2026-11-16.md)）：抄底类触发在全样本等权指数**低于** MA200 时表现更好（盈亏比约 1.3），在指数强势、宽度高时更差（约 0.6–0.8）。合理解释是：大盘普跌时个股破底多是被动错杀，大盘强势时个股还在破底，多半是它自己出了问题。所以闸门不能简单写成「指数在 MA200 下就减仓」，而要**按策略类型分开**：抄底类在「普跌后企稳」环境里给满仓位系数，在「大盘强、个股独弱」时降为 0.5 或跳过；追强类（D3 高点吸收）才用「指数在 MA200 上」作为条件。这个结论来自少数几轮大级别下跌，独立样本不多，需要更长数据复核。

## 模块 A：股票池扫描（每日盘后跑全市场）

老王每天用 Delta%、收盘位置、POC 位置、5/10/20 日涨跌给 59 只自选排序。我们把筛选写成规则，输出一张排序表。

**硬过滤**（全部满足才进池）：

- 非 ST、上市 ≥ 250 个交易日、当日未停牌。
- 20 日平均成交额 ≥ 5000 万元（保证能进能出，按资金量调整）。
- 120 日最大回撤 `DD120 = 1 − L_t / max(H, 120)` ≥ 30%，**或**处在 C 模块的「吸筹簇」里。

**排序列**：

| 列 | 定义 |
|---|---|
| `Pos120` | `(C − min(L,120)) / (max(H,120) − min(L,120))`，越低越在底部 |
| `VolDry` | `MA(V,5) / MA(V,20)`，< 0.7 为量枯 |
| `潜伏分`、`青蛙分` | 来自模块 D |
| `POCPos60` | 当日（或近 5 日）POC 在 60 日高低区间里的位置 |
| `Delta%₅` | 近 5 日 Delta / 近 5 日成交量 |
| `CL` | 收盘位置 |
| `妖股基因` | 近 250 日涨停次数（小盘题材股的历史活跃度） |
| `R5/R10/R20` | 5/10/20 日涨跌幅 |

排序主键：`潜伏分` 降序，次键 `Pos120` 升序。前 30–60 只进「观察池」，每天只对观察池跑后续模块和人工复核，这和老王「自选股票池规范」视频的做法一致。

## 模块 B：衰减筹码分布（成本结构）

### 计算

价格轴按 `Δp = max(最小跳动, 0.002 × C)` 分格。每天：

1. 当日换手率 `τ = V / 流通股本`。
2. 旧筹码衰减：`D_t(p) = (1 − α·τ) × D_{t−1}(p)`，`α` 为衰减系数（默认 1）。
3. 新筹码加入：总量 `α·τ`，在 `[L, H]` 上按三角分布摊开，峰值在当日均价 `VWAP_d = 成交额 / 成交量`（无成交额时用 `(H + L + 2C)/4`）。

这是通达信、同花顺「成本分布」的标准思路；老王说的「衰减换手模型」指的就是它。

### 稳定筹码（「保留率过滤」）

同时维护一份「老筹码」分布：`D_old,t = D_{t−S} × Π_{j=t−S+1..t}(1 − α·τ_j)`，即 S 天前已有、至今没被换掉的筹码，S 默认 20（老王参数「检查筹码稳定性 20 天」）。

- 稳定筹码占比 `Stable = Σ D_old / Σ D`
- 某价位的保留率 `ρ(p) = D_old(p) / D(p)`，`ρ ≥ 0.5` 且该格占比 ≥ 0.5% 的连续价位 = **稳定筹码区间**（紫色）

### 输出

| 输出 | 定义 | 用途 |
|---|---|---|
| 获利比例 `Profit` | 低于收盘价的筹码占比 | < 10% = 几乎全员套牢（底部特征）；> 90% 且 `Stable` 下降 = 派发 |
| 70%/90% 成本区间 | 累积分布 15%–85% / 5%–95% 分位 | 支撑压力带 |
| 集中度 | `(P95 − P5) / (P95 + P5)` | 越小越集中，吸筹完成的标志之一 |
| 主力成本区 | 稳定筹码区间里筹码量最大的一段 | 主力大本营 |
| N 日亏损比例 | 近 N 日新增的筹码里，当前处于亏损的比例（N = 3/5/10/20） | 短线套牢盘压力 |

### 注意

- 流通股本需要历史值（解禁会突变）。Yahoo 没有，Tushare `daily_basic` 有。没有时用 `τ = V / median(V, 250) × 基准换手率` 近似，结果只能看形状，不能看绝对比例。
- 筹码分布本质是**模型**，不是真实持仓。它的价值在于给出客观、可回测的支撑压力位，不在于「看穿主力」。

## 模块 C：HVN 簇状态机（支撑框 + 黄金坑）

直接借鉴老王热力图 Pro 的状态机，这是他公开材料里最工程化、最值得抄思路的部分。

### 簇的生成（只在生成时计算一次，之后冻结）

1. 每根 K 线收盘后，用最近 `W = 14` 根做局部成交量分布，价格格宽 `s = 0.1 × ATR14`。
2. 每根 K 线的量按 L2/L3 方式摊到它覆盖的价格格（有小周期数据时按小周期价位摊）。
3. 格量 ≥ `3.2 ×` 平均格量的格为高亮格；连续 2–4 个高亮格组成一个 HVN 簇，边界 `[lo, hi]`。
4. 新簇与已有活跃簇重叠超过 50% 时不新建（防叠框）。
5. 簇生成后上下沿**永久固定**，这样回放和实盘一致，不会重绘。

### 状态转移

| 当前状态 | 条件（收盘价判定） | 下一状态 |
|---|---|---|
| 吸筹簇 | 连续 2 根收盘 > hi | 铁底支撑 |
| 吸筹簇 / 铁底支撑 | 收盘 < lo − 0.15·ATR | 跌破观察（计时开始） |
| 跌破观察 | 3 根内收盘重新 > lo，**且**当根 `CL ≥ 0.6`，**且**当根 Delta% > 0 | **黄金坑（Spring）** → 视作铁底支撑 |
| 跌破观察 | 3 根内没收回 | 截断（停止延伸，历史保留为灰框） |
| 铁底支撑 | 回踩 `L ≤ hi` 且收盘 ≥ lo，当根 Delta% > 0 | 发「回踩确认」事件 |

黄金坑条件里的 `CL` 和 Delta% 是我们相对老王的加强：只靠「价格收回」容易被下一次下跌骗，要求收回当根收在上部且主动买为正。

### 输出事件

`HVN_NEW`、`IRON_FLOOR`（铁底确认）、`SPRING`（黄金坑）、`RETEST_OK`（回踩确认）、`CUT`（截断）。前三个是入场候选，`CUT` 是持仓的止损条件之一。

## 模块 D：资金身份分（我们版本的 MMOF）

### 四个子分

**D1 潜伏分（0–100）**：借鉴老王⓪，五个条件各 20 分，前两个是必须条件。

| # | 条件 | 默认 |
|---|---|---|
| 1 ★ | `Pos120 ≤ 0.35` | 低位 |
| 2 ★ | `VolDry = MA(V,5)/MA(V,20) ≤ 0.7` | 量枯 |
| 3 | 近 5 日主动卖量 < 前 5 日主动卖量 | 卖压收缩 |
| 4 | `ATR5 < ATR14` 的 0.8 倍 | 波动收窄 |
| 5 | 近 20 日价格创新低，但累计 Delta `CVD` 没有创 20 日新低 | 有人接 |

★ 不满足则 D1 = 0。

**D2 青蛙分（−100..100）**：`Frog = clip(3 × ΣΔ₂₀ / ΣV₂₀ × 100, −100, 100)`。上穿 30 = 资金持续流入启动，用来区分「底部真有人买」和「只是跌不动」。

**D3 高点吸收（0/1 事件 + 0–100 分）**：`C ≥ 0.95 × max(H,252)` 且 `C > VWAP20` 且 `CL ≥ 0.6` 且 Delta% > 0。突破 252 日高点当根同时满足 → `ABSORB_BREAK` 事件。用于拉升中段加仓，不用于底部入场。

**D4 POC 阶段**：当日 POC（有小周期数据时取当日成交最大的价格格，否则取 `VWAP_d`）在 60 日高低区间里的位置 `POCPos60`，Delta% 用 5 日均值并按 `0.5 × σ₂₀(Delta%)`（下限 0.02）判方向：

| `POCPos60` | 平滑 Delta% | 阶段 | 含义 |
|---|---|---|---|
| < 0.4 | > 门槛 | 早期吸筹 | 观察 / 可入场 |
| 0.4–0.8 | > 门槛 | 拉升 | 持有 |
| > 0.8 | > 门槛 | 晚期 | 持有但收紧止盈 |
| > 0.8 | < −门槛 | **派发警告** | 分批减仓 |
| 任意 | 在 ±门槛内 | 中性 | — |

### 跨股票可比

不同股票的 Delta%、量枯程度差异很大。原始分数用于单股看图；**用于选股排序时，每个子分换成该股自身过去 250 日的分位数**，再合成：`D = 0.15·D1 + 0.35·D2 + 0.25·D3 + 0.25·D4`（初值借鉴老王权重，验证后用样本外表现重估）。

刹车（模块 0）触发时 D 强制为 0。

> **日线原型结果**：只用日线 CLV 估算 Delta（L3）时，「青蛙分 > 0」作为过滤条件让信号**更差**（20 日超额从 −1.2% 降到 −1.6%）。原因是 L3 的 Delta 本质上就是「最近几天收在高位」，A 股短线有反转效应，收得越强后面越弱。结论：D2、D4 和 D1 的第 5 条依赖真实主动买卖，**必须用 L1/L2 数据**，L3 版本只能看图，不能进选股或入场规则。D1 潜伏分作为过滤有改善迹象（F 激进版加上潜伏分后超额从 −1.2% 收窄到 −0.4%，但不显著）。

## 模块 E：实体谱雷达

老王「实体闭环雷达」的思路是：只看实体、做傅里叶分解、主要结构压过杂音时锁定。我们把它写成一个有统计意义的检验。

### 定义

取最近 N 根（默认 120）K 线：

1. 标准化实体 `b_j = (C_j − O_j) / ATR14_j`，去均值 `b̃_j = b_j − mean(b)`。
2. 「闭环」：实体累加得路径 `P_j = Σ_{i≤j} b_i`，减去首尾连线 `Q_j = P_j − (j/(N−1))·P_{N−1}`，路径首尾相接，成为闭合曲线。
3. 「旋转臂」：对 Q 做离散傅里叶变换，第 k 个臂 `c_k = Σ_j Q_j·e^{−2πijk/N}`，k = 1..M（默认 M = 30）。
4. 「白化」：随机游走路径的臂长天然按 1/k 衰减，低阶臂永远最大，不白化会一直「锁定」。乘以 `w_k = 4 sin²(πk/N)` 后，`p_k = w_k |c_k|²` 在实体完全随机时是平的。差分后再做 DFT 会多出因子 `|1 − e^{−2πik/N}|² = 4 sin²(πk/N)`，所以「闭环 + 白化」在端点约定差异之外等价于直接对去均值的实体 `b̃` 做周期图，也就是实体序列的功率谱。代码里就是这样算的。
5. **回波**：`E = 10·log₁₀( mean_{k≤K} p_k / mean_{K<k≤M} p_k )`，K 默认 6（老王参数）。

### 为什么这个量有意义

实体之间独立时，每个 `p_k / σ²` 近似服从均值为 1 的指数分布，所以回波的比值近似服从 **F(2K, 2(M−K)) = F(12, 48)** 分布。这给出不依赖经验的门槛：F(12,48) 的 95% 分位为 **2.9 dB**，99% 分位为 4.1 dB。`lwai_lab.py null` 用 2 万次随机实体模拟复核，模拟分位和 F 分布分位相差不到 0.02 dB。老王的「最低回波 3 dB」正好落在 95% 显著性附近，他的门槛很可能也是这样来的。

> **日线原型结果**：在 411 只 A 股 2015–2026 年的日线上，实测回波的分布和随机实体几乎重合（95% 分位 2.85 dB 对 2.91 dB，超过 3 dB 的时间占 4.2%，随机为 5%）。也就是说，**A 股日线实体序列在 20 根以上的周期上基本是白噪声**，日线雷达的「锁定」大多是在锁定噪声；起爆多信号的 20 日超额为 −1.8%（t = −2.3）。这个模块在日线上不该作为入场依据。还值得试的方向：放到 5 分钟或 15 分钟 K 线上；或把输入从实体换成真实 Delta 序列（主动买卖的持续性可能比实体更有结构）；都不行就删掉。

回波高 = 低频（周期 ≥ N/K = 20 根）的实体结构明显强于高频杂音 = 实体有持续性（连续同向的阳线或阴线）= 「有方向」。

### 信号

| 信号 | 条件 |
|---|---|
| 锁定（迟滞） | 进门：`E > max(3 dB, μ₂₀₀(E) + 1.5·σ₂₀₀(E))`；出门：`E < μ₂₀₀ + 0.5·σ₂₀₀` |
| 方向 | 低频重建的最后一段斜率：`dir = sign(Σ_{k≤K} Re(c_k·(e^{2πik(N−1)/N} − e^{2πik(N−2)/N})))`，或更简单地用最近 5 根 `b` 的和 |
| 起爆多 / 空 | 由未锁定变为锁定的那根，`dir` 与当根实体同号；同类信号冷却 10 根，反向冷却 5 根 |
| 偏离倍数 | `Dev = (C − EMA(C, 120)) / mean(|C − EMA(C,120)|, 100)` |
| 狂热见顶 | 近 3 根内 `Dev ≥ 3` 且当根 `Dev` < 近 3 根最大值，当根为阴线，且 E 处于锁定 |
| 绝望见底 | 对称：`Dev ≤ −3` 后回升、当根为阳线、E 处于锁定 |

用法：E 是**注意力过滤器**。底部模块给出候选后，E 起爆多可以作为第三族确认；绝望见底可以作为模块 A 的额外入池条件；狂热见顶是持仓的减仓条件之一。

计算量：每根 K 线 N × M = 3600 次乘加，Pine 里限制在最近 1500 根计算即可。

## 模块 F：破底站稳触发（我们的「黄色闪光」）

老王的「破底站稳关键 K」只公开了参数（120 天、30%、MA20、三重条件）。我们给出明确定义，并分激进、稳健两档，用验证结果决定用哪档。

### 条件

| # | 条件 | 定义 |
|---|---|---|
| F1 深跌 | 当根或近 5 根内 `DD120 ≥ 30%` | 已经充分下跌 |
| F2 破底 | 近 5 根内出现 `L < min(L, 20)₋₁`，记该最低点为 `Lx` | 先打掉前低的止损盘（扫流动性） |
| F3a 站稳·激进 | 当根收盘 > 被跌破的前 20 日低点，`CL ≥ 0.6`，且当根为阳线 | 收回 |
| F3b 站稳·稳健 | `Lx` 之后 10 根内收盘 > MA20，期间未再跌破 `Lx` | 结构转强 |
| F4 资金（可选） | 当根 Delta% > 0；有 L1/L2 数据时，`Lx` 附近 ±1 ATR 内出现 ≥ 3 层堆叠买失衡（买量 ≥ 3 × 对角卖量） | 有人真金白银接 |

信号 = F1 ∧ F2 ∧ (F3a 或 F3b)，F4 作为加分和优先级。同一只股票 20 根内只发一次。

### 自带的风控锚

- 初始止损 = `Lx − 0.2·ATR14`。
- F4 的买失衡堆叠价位画成向右延伸的平行线，被后续 K 线收盘穿过即作废（借鉴老王「截断判定」）。这些线是加仓和止损上移的参考。

### 和流动性扫单的关系

F2 本质是「扫掉前低流动性」。如果前低恰好是模块 C 的 HVN 簇下沿或一个放量枢轴低点（老王「流动性区域」的 Z 值过滤枢轴），信号质量应该更高。验证时单独统计这个子集。

> **日线原型结果：未通过。** 激进版 6651 次、稳健版 7203 次信号，20 日超额分别为 −1.2%、−1.35%（t ≈ −5 到 −6），比「随便买一只跌了 30% 的股票」还差；按规则止损、时间止损、跟踪止盈做成交易，盈亏比约 1.05，扣成本后接近零。加涨停基因（近 250 日涨停 ≥ 3 次）、加青蛙分都没有改善；我们定义的「单阳不破」也是负超额。老王晒单股票上的 F 信号和他的实际 B 点基本对不上。结论：**只用日线 OHLCV 的破底站稳形态在 A 股没有优势**，这和老王自己说「单用盘整框和 VP 回测胜率低」是一回事。F 只能作为「结构上可能见底」的候选标记，入场必须依赖 L1/L2 订单流（失衡堆叠、吸收）或筹码（获利比例极低、稳定筹码锁仓）这类日线里没有的信息，并且要单独验证这些信息的增量。

## 模块 G：执行与退出

老王的晒单显示：底部 1 次或分批买，急拉段 3–7 笔分批卖，「翻倍出本」。我们把它写成规则，加上他没公开的部分：亏损时怎么办。

### 仓位

- 单笔风险 `R = 1% × 权益 × g`（g 来自模块 0）。
- 股数 = `R / (入场价 − 止损价)`，向下取整到 100 股。
- 单只上限 20% 权益；同时最多 6 只；同一题材最多 2 只。
- A 股 T+1：入场当天不能止损，所以止损距离过大（> 12%）的信号直接放弃，不缩仓硬上。

### 入场

- 信号 K 收盘确认后，下一交易日开盘买入。开盘一字涨停买不进 → 放弃，不追（回测必须同样处理）。
- 第一笔 50%。浮盈 ≥ 1R 且出现 `IRON_FLOOR` / `RETEST_OK` / D2 青蛙上穿 30 之一时，加剩余 50%，加仓后整体止损上移到成本价附近。

### 退出（先到先执行）

| 规则 | 动作 |
|---|---|
| 硬止损 | 收盘 < 止损价 → 次日开盘全部卖出 |
| 结构失败 | 所依托的 HVN 簇 `CUT` → 全部卖出 |
| 时间止损 | 入场 40 个交易日仍未达到 +1R → 卖出（潜伏失败，资金换去别处） |
| 出本 | 涨幅 +100% 时卖出成本对应的仓位（约一半），剩余为纯利润仓（老王「翻倍出本」）；资金小时可改为 +2R 先卖 1/3 |
| 派发警告 | D4 进入「派发警告」或 E 发「狂热见顶」→ 剩余仓位分 3 天卖完 |
| 跟踪止盈 | 浮盈 > 2R 后启用吊灯止损 `max(H,22) − 3·ATR22` |
| 连板断板 | 连续涨停后首次开板且收盘不封板 → 卖 1/3 |

## 模块 H：个股状态机（把一切连起来）

```
       A 硬过滤通过              D1 ≥ 85 或 Profit < 10%
池外 ───────────────▶ 观察 ───────────────────────────▶ 潜伏
  ▲                    │                                    │
  │                    │ DD120 回到 < 15% 或 60 天无事件      │ F 信号 / C:SPRING / C:IRON_FLOOR
  │                    ▼                                    ▼
  └───────────────── 移出 ◀──────── 离场 ◀──── 持有 ◀──── 入场（需两族同意 + 闸门 g > 0）
                                     ▲         │
                                     └─ 出本 ◀─┘（+100% 或 +2R）
```

入场的「两族同意」具体是：

- **触发**（必选其一）：F 信号；C 的 `SPRING`；C 的 `IRON_FLOOR`；E 的起爆多（只有在 D2 > 0 时才算）。
- **确认**（另选一个不同族）：结构族 = 价格在 B 的主力成本区附近或上方 / C 有活跃铁底；资金族 = D2 青蛙分 > 0 且近 5 日 Delta% > 0；时频族 = E 锁定且方向向上。

每一次入场记录：触发类型、确认类型、各模块数值、数据级别。之后所有统计都按这些标签拆开看，这样才知道哪一层在贡献收益。

## 落地成 TradingView 指标的拆分方案

老王有 36 个脚本，很多功能重叠。我们只做 4 个，减少维护量，也避免「指标越多越像在复现过去」：

| 脚本 | 内容 | 类型 |
|---|---|---|
| ① 结构位 | B 衰减筹码 + C HVN 状态机 + F 的失衡平行线 | 主图叠加 |
| ② 资金身份 | D1–D4 + 综合分 + 刹车背景 + 信息表 | 副图 |
| ③ 触发器 | F 破底站稳 + E 实体谱雷达 + 统一的警报 | 主图标签 + 副图回波 |
| ④ 交易面板 | G 的仓位计算、止损线、出本线、跟踪止盈线 | 主图 |

Pine 实现要点：

- 小周期数据用 `request.security_lower_tf()`；真实主动买卖量用 TradingView 的 Footprint 请求（Premium 才有，Pine v6 文档里查 `request.footprint` 的最新用法），拿不到时按降级链回退。
- 所有状态（HVN 簇、失衡线）存在 `var` 数组里，只在收盘确认的 K 线上更新，`barstate.isconfirmed` 之外不改状态。
- 枢轴类信号（流动性区域）天然滞后 `len` 根，信号只能标在**确认当根**；老王的缠论脚本也是这样做的（「真实确认时间」虚线）。
- 全市场扫描（模块 A）不放在 Pine 里，用 Python 盘后跑，结果导出成 TradingView 自选列表；或用 TradingView 的 Pine Screener 对观察池跑 ②③。
