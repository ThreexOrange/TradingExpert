## 参数与警报

```
[① 数据源]
   - 使用成交量轨迹(Premium) = True  // 开：用真实的主动买卖量。需要 Premium。 关或无权限：自动退回估算模式。
   - 每格跳数 = 5  // 轨迹里一格价格包含几个最小跳动。 数字大，格子少，计算快，但粗。 A 股日线建议 5 到 10。
   - 价值区% = 70  // 价值区 = 成交最集中的那一段价格。 70 表示包含 70% 的成交量。
   - 失衡% = 300  // 失衡 = 一边的量是另一边的几倍。 300 表示买量是卖量 3 倍才算买失衡。
   - 无轨迹时用小周期估算 = True  // 没有轨迹时，把小周期 K 线的阳线算买、阴线算卖。 比单根估算准。
   - 估算用小周期 = '5'  // 估算用哪个小周期。日线用 5 分钟或 1 分钟。 周期越小越准，但历史长度受限。
   - 收盘位置含跳空 = True  // 开：把昨收算进当天区间。 一字板时收盘位置才会是 1 或 0，而不是 0.5。
   - 一字板识别 = True  // 开：最高等于最低时，涨记全买，跌记全卖。 顶部画菱形标记。

  [⓪ 潜伏吸筹]
   - 位置区间长度 = 120  // 用多少根 K 线算高低区间。 120 = 半年。判断股价是不是在低位。
   - 低位阈值 = 0.35  // 股价在区间的位置低于多少算低位。 0.35 = 下面 35%。必须条件。
   - 量枯倍数 = 0.7  // 近期均量低于长期均量的多少倍算量枯。 0.7 = 只有 7 成。必须条件。
   - 均量长度 = 20  // 长期均量用多少根 K 线。默认 20。
   - 卖压对比窗口 = 5  // 最近 N 天的卖量和前 N 天比。 变小算卖压收缩。也用于短期均量和 ATR 对比。
   - ATR长度 = 14  // ATR = 平均每天的振幅。 ATR 变小 = K 线变小 = 波动收窄。
   - 背离回看长度 = 20  // 背离 = 价格创新低，累计 Delta 没创新低。 说明砸盘时有人在接。回看多少根。
   - 潜伏触发分 = 85  // 五个条件各 20 分，满分 100。 低位和量枯是必须条件，不满足直接 0 分。 85 以上 = 至少满足 5 个。想更敏感就调到 60。

  [② 方向一 青蛙]
   - 累计窗口 = 20  // 累计多少根 K 线的 Delta。 越长越平滑，信号越慢。
   - 占比放大倍数 = 3  // 累计 Delta 占比通常很小。 乘这个倍数放大，让分数接近 -100 到 100。
   - 青蛙启动分 = 30  // 青蛙分向上穿过这个数就发警报。 分数一直在这个数以上 = 青蛙持续中。
   - 显示青蛙标记 = True  // 开：启动日底部画紫色箭头。 持续期柱子顶部加紫色描边线。

  [③ 方向二 高点]
   - 高点回看(52周) = 252  // 找多少根 K 线内的最高价。252 = 一年。
   - 锚定区阈值 = 0.95  // 收盘价高于最高价的多少倍算靠近高点。 0.95 = 离高点 5% 以内。淡黄背景。
   - 盈利盘VWAP长度 = 20  // VWAP = 按成交量加权的平均价。 收盘高于它，说明近期买入的人多数在赚钱。
   - 买失衡最少格数 = 3  // 至少几格出现买失衡才算买方强。 无轨迹时用 Delta 占比估算格数。
   - 收盘位置最低 = 0.6  // 收盘在当天区间的位置。 0.6 = 收在上面 40% 才算强。

  [④ 方向三 POC]
   - POC位置区间长度 = 60  // POC = 成交最多的价格。 看 POC 在多少根 K 线的高低区间里的位置。
   - 早期上限 = 0.4  // POC 位置低于这个数算早期。 0.4 = 区间下面 40%。绿色。
   - 出货下限 = 0.8  // POC 位置高于这个数算晚期或出货。 0.8 = 区间上面 20%。买多是黄，卖多是红。
   - Delta平滑长度 = 5  // Delta 占比平均几天再判阶段。 避免一天的噪音改颜色。
   - 门槛标准差长度 = 20  // 标准差 = 数字平时晃动多大。 用多少根 K 线算。
   - 门槛=标准差x = 0.5  // 门槛 = 标准差乘这个数。 Delta 占比超过门槛才算有方向。 数字小，更容易出绿红；数字大，更多灰。
   - 门槛下限 = 0.02  // 门槛最低不能低于这个数。防止全是绿红。

  [⑤ 崩盘刹车]
   - 刹车模式 = '大盘且个股'  options=['只看大盘', '只看个股', '大盘且个股', '关闭']  // 刹车 = 暴跌时分数归零，柱子变暗红。 只看大盘：大盘暴跌就刹。 只看个股：个股暴跌就刹。 大盘且个股：两个都暴跌才刹。最少误判。
   - 自定义基准(留空自动) = ''  // 大盘用哪个指数。留空自动选： A 股上证、港股恒指、加密 BTC、其他 SPX。
   - 均线长度 = 200  // 价格跌破这条均线才可能刹车。200 = 年线。
   - 波动飙升倍数 = 1.5  // 当前 ATR 是平时 ATR 的多少倍算飙升。 1.5 = 比平时大 50%。
   - 个股下跌确认天数 = 5  // 个股收盘要低于 N 天前才算在跌。 防止连板打开后放量被误判为崩盘。

  [⑥ 权重与显示]
   - 权重 潜伏 = 0.15  // 潜伏分占综合分的比例。四个权重加起来建议 = 1。
   - 权重 青蛙 = 0.35  // 青蛙分占综合分的比例。
   - 权重 高点 = 0.25  // 高点吸收分占综合分的比例。
   - 权重 阶段 = 0.25  // 阶段分占综合分的比例。
   - 显示信息表 = True  // 右上角的数值表。
   - 显示背景色 = True  // 淡蓝 = 潜伏中。淡黄 = 锚定区。淡红 = 刹车中。

  ALERTS/PLOTS:
   - 综合分 | 
   - 一字跌停 | 
   - 青蛙启动 | 
   - 潜伏启动 | 
   - MMOF 潜伏吸筹启动 | 潜伏吸筹分达到阈值：低位+量枯+卖压衰竭
   - 青蛙分 | 
   - 潜伏分 | 
   - 青蛙描边 | 
   - 刹车背景 | 
   - 潜伏背景 | 
   - 高点突破 | 
   - 一字涨停 | 
   - 锚定区背景 | 
   - MMOF 青蛙动量启动 | 青蛙分向上突破启动线
   - MMOF 高点吸收突破 | 锚定区内突破 52 周高点且 Delta 为正
   - MMOF 出货警告 | POC 高位且 Delta 转负
   - MMOF 崩盘刹车 | 崩盘刹车触发，分数归零
```

## 作者公开说明（中文部分）

# LWAI 多身份动量订单流 MMOF 指标介绍
## 一句话说明
这是一个副图指标，把"钱到识别出主力、锁仓资金、点火资金识别身份后，分析在买还是在卖"，变成一根彩色柱子，让你一眼看懂目前盘面的动作。
---
## 它是什么
- 名字：LWAI 多身份动量订单流 MMOF
- 类型：副图指标（画在价格图下方，不遮挡 K 线）
- 核心作用：把看不见的不同身份的资金流向，变成看得见的颜色和信号
---
## 它能干什么（五大功能）
### 1. 潜伏吸筹（方向零）
作用：找出主力偷偷进货、还没拉升的时机。
好处：在行情启动前提前发现，避免追高，占得先机。
### 2. 温水煮青蛙动量（方向一）
作用：捕捉那种"慢慢涨、不声张"但持续不断的买盘力量。
好处：发现看似平静、实则资金持续流入的强势股。
### 3. 高点吸收（方向二）
作用：判断股价靠近一年高点时的上涨，是真的突破还是假的。
好处：区分真突破和假突破，减少追高被套。
### 4. POC 生命周期（方向三）
作用：看成交最密集的价格落在什么位置，判断当前处于吸货、拉升还是出货阶段。
好处：清楚自己站在行情的哪个阶段，决定该进还是该出。
### 5. 崩盘刹车
作用：大盘或个股暴跌时，自动把信号清零、柱子变暗红。
好处：在恐慌下跌中避免误信买入信号，保护你不被套。
---
## 它的优势
1. 数据永不罢工：优先用最真实的买卖数据，没有就自动降级，始终有结果。
2. 自动认市场：自动识别 A 股、港股、加密货币，并选对对应的大盘指数。
3. 一眼看懂：彩色柱子 + 右上角文字信息表，不用自己动手算。
4. 新手友好：每个参数都配了白话解释，调起来不费劲。
5. 自动提醒：关键信号（吸筹启动、突破、出货、刹车）都能设置警报，不用一直盯盘。
---
## 好处总结
- 把复杂难懂的订单流，变成"看一眼颜色就明白"。
- 覆盖"吸货 → 拉升 → 出货"整个完整周期。
- 自带刹车保护，帮你避开暴跌。
- 新手老手都适用。
