### 关于「流动性黑洞必定迎来涨停」

- 截图 27 是他查的 MBA 百科「流动性黑洞」：Persaud 提出的概念，指市场参与者行为趋同、同向抛售时流动性瞬间消失、价格加速下跌。原意是**危机**，不是涨停。
- 他的用法是「回到中部流动性黑洞区间必买」（夹B），以及 2025-07 的私密指标「流动性黑洞预警」（简介写「提前捕捉涨停、跌停等极端行情」，「从 3 个关键维度」评分）。这个指标不公开，没有任何图表快照，**目前没有办法检验「必定涨停」**。
- 「必定」本身就不可能成立：同一个指标简介里也写了「跌停」。能检验的方式只有一种：拿到它在过去所有股票上的全部信号（包括没涨停的），统计 N 日内涨停的比例，和随机日子的基准比。可以请有权限的人导出信号，或者你看视频时把他演示时用的黑洞区间定义记下来，我们写成规则测。

### 精确还原的公式（用他的数值逐根验证）

| 项目 | 公式 | 验证 |
|---|---|---|
| 雷达·进门门槛 | 前 200 根回波的均值 + **2.0** × 总体标准差（不含当根） | 1301 根全部吻合，残差 3×10⁻¹⁴ |
| 雷达·出门门槛 | 前 200 根回波的均值 + 0.5 × 总体标准差 | 全部吻合，残差 < 10⁻⁴ |
| 雷达·中枢（黄线） | 收盘价 120 日简单均线 | 中位相对误差 0.09%（复权差异） |
| 雷达·计算范围 | 只算最后 1500 根（1602 − 1500 = 第 101 根起有值），门槛再晚 200 根 | 吻合 |
| 雷达·偏离倍数 | 约等于 `ln(收盘/SMA120)` 除以它近 120 根的标准差 | 相关 0.99，不完全吻合 |
| 雷达·回波本身 | 实体累加成闭环后做傅里叶分解，前 K 个臂对其余臂的能量比（dB） | 只到相关 0.58，具体的「闭环」构造和白化方式还没对上 |
| MMOF·潜伏分 | 我们 02 号文档 D1 的五条件规则 | 349 天里「是否 > 0」的判断 **99.7% 一致**（他 44 天，我们 43 天） |
| MMOF·青蛙分 | 3 × 20 日累计 Delta ÷ 20 日成交量 × 100，Delta 来自真实成交量轨迹 | 用日线 CLV 估算的版本与他相关 0.70，但波动是他的 **3 倍**（标准差 48 对 15） |

青蛙分这一条很关键：日线估算的 Delta 方向大致对，但幅度严重失真。这解释了第一轮回测里「青蛙分 > 0」过滤反而变差：我们用的不是他的数据。

K1 做成交易（止损、时间止损、跟踪止盈同第一轮）：1061 笔，胜率 34.6%，平均 −0.57%，盈亏比 0.92。

**加上冲击 K、放量、涨停这些更像他的条件后，结果更差，不是更好。** A 股小票里「深跌后第一根大阳/涨停」之后平均是回吐的。和第一轮一起看，结论很一致：

1. 他的买点**形态本身**（无论是我们的定义还是按他的信号还原的定义）在日线上没有优势，甚至是负的。
2. 大纲把形态放在最后一步，前面要求「主力痕迹必须出现信号」+「形态整理」+「主力 KPI 全部满足」。如果他的方法真有优势，只能来自这些**过滤条件**：订单流大单、筹码锁仓、试盘涨停的识别，以及只做「3% 的国宴菜肴」那种极少数票的筛选。
3. 所以下一步要测的不是更多形态，而是**过滤条件本身有没有增量**：在 K1/B1 的信号里，按「大单净买入 > 0」「筹码获利比例 < 10%」「稳定筹码占比高」分组，看能不能把负超额扭成正的。这需要 Tushare 的分单资金流和换手率数据。

## 四、对我们体系的修改

- 模块 F 增加「冲击版」触发（K1），并按他的实际参数把跌幅门槛设为 35%、窗口用 120 根；同时在 03 号文档里标注 K1、B1 未通过。
- 模块 E 采用已经验证的门槛公式（μ + 2σ 进、μ + 0.5σ 出，200 根，不含当根）和 SMA120 中枢；回波构造保留我们自己的统计定义，它在日线上本来就接近噪声。
- 模块 D 确认 D1 规则可用；D2/D4 必须用真实主动买卖数据，不能用日线估算。
- 模块 H 的状态机按他的买点体系细分为 1B / 夹B / 2B / 3B-NB / 拿B / S，每类单独记录和统计，方便以后看哪一类真有用。
- 「主力 KPI」清单变成入场前的检查表：每一项都要对应一个可计算的指标和阈值，算不出来的项目不进规则。
