从截图可读的简介里抽出的关键句：

- **B 位定位器**：「结合**拉普拉斯变换和卡尔曼滤波**技术，能够精确定位市场从底部开始的转折点」。
- **关键黄金坑识别**：「基于资金潮汐理论……类似海啸前的海水退潮现象……识别价格在重要支撑/阻力位附近」的「黄金坑」形态。
- **包络线**：「专门用于配合黄金坑识别的市场多空力量确认」，含力量对比和趋势方向。
- **流动性黑洞预警**：「预测股价即将发生的剧烈波动……提前捕捉涨停、跌停等极端行情」，「多维度评分，从 3 个关键维度」。
- **盘口情绪流动性比率**：「融合情绪因子、黑洞流动性理论和 LWAI 识别体系的**打板时机**捕捉指标……针对已完成盘力整理的股票，在最接近涨停板触发的关键时刻提供入场信号」。
- **吸筹效率**：「基于**市场结构极性转换（S/R Flip）**……捕捉主力资金在关键价格水平的控盘痕迹，不依赖均线或震荡指标」。
- **砸盘 B 检测器**：「专门针对中国 A 股……识别主力关键价位建仓交易后的回调整理股票」，两类信号：「买入信号（主力建仓或托盘痕迹）」和「启动信号（建仓后适合进场的安全价位）」。
- **砸盘 B-多洗版**：「识别涨停股票回调后的低风险买入机会」，「多洗版」= 经过多次洗盘筛选。
- **亏损日识别**：「散户极致亏损的日子就是反弹的开始」，标 A 信号作为后续分析的基准锚点。
- **暴力洗盘**：在 K 线上打「洗」字，提示一次洗盘结束；右侧统计该信号历史累计次数。
- **主力操盘进度-急拉版**：把行情分为 **6 个可辨的阶段**并标关键点。
- **多因子聚类**：波动率、趋势强度、顶底识别加**机器学习聚类**。
- **统计分析**：当前标的对 5 个参照标的的相关系数、Beta、Alpha 等（截图里的参照是股指期货 CFFEX 合约）。
- **指标共振**：MACD、随机指标、布林、成交量、RSI、PSAR、DMI、MFI 等逐项投票，汇总成多空一致性。

## 二、7 个邀请制指标：公开页暴露的参数蓝图

发布页上的图表会把指标的**全部输入项**（名称、默认值、分组、白话提示）和**警报文案**一起下发到浏览器。源码锁着，但参数结构等于半张设计图。原文存在 [附录_公开页参数原文](附录_公开页参数原文/)。下面是逐个解读。

### 1. MMOF 多身份动量订单流（副图综合分）

把「主力 / 锁仓 / 点火」三类资金的行为压成一根彩色柱。参数直接给出了评分公式的骨架：

| 模块（权重） | 公开参数 | 还原的计算 |
|---|---|---|
| ⓪ 潜伏吸筹（0.15） | 位置区间 120 根；低位阈值 0.35；量枯倍数 0.7（20 日均量）；卖压对比窗口 5；ATR 14；背离回看 20；触发分 85 | 五个条件各 20 分：①价格在 120 日区间下 35%（**必须**）②近 5 日均量 < 0.7×20 日均量（**必须**）③近 5 日卖量 < 前 5 日卖量 ④ATR 收缩 ⑤价格创 20 日新低而累计 Delta 没创新低。两个必须条件不满足直接 0 分 |
| ② 青蛙动量（0.35） | 累计窗口 20；占比放大 3 倍；启动分 30 | 青蛙分 = 3 × Σ₂₀Delta ÷ Σ₂₀Volume × 100，上穿 30 = 「温水煮青蛙」启动 |
| ③ 高点吸收（0.25） | 52 周高点 252；锚定区 0.95；盈利盘 VWAP 20；买失衡最少 3 格；收盘位置 ≥ 0.6 | 收盘 ≥ 0.95×252 日最高 + 收在 20 日 VWAP 上方 + 收盘位于当日区间上 40% + 至少 3 个价格格出现买方失衡；突破 52 周高点且 Delta 为正 → 「高点吸收突破」 |
| ④ POC 生命周期（0.25） | POC 区间 60；早期 < 0.4；出货 > 0.8；Delta 平滑 5；门槛 = 0.5×σ₂₀，下限 0.02 | 当日 POC 在 60 日高低区间里的相对位置 → 早期（绿）/中段/晚期（买多黄、卖多红）；**POC 高位 + Delta 转负 = 出货警告** |
| ⑤ 崩盘刹车 | 模式「大盘且个股」；200 日均线；ATR 飙升 1.5 倍；个股下跌确认 5 天 | 大盘和个股都在 200 日线下、ATR 是常态 1.5 倍以上、收盘低于 5 天前 → 综合分强制归零 |

数据降级链：有 Footprint 用真实主动买卖量；没有就用 5 分钟 K 线「阳线算买、阴线算卖」估算；一字板（高 = 低）涨记全买、跌记全卖。收盘位置把昨收算进区间，这样一字板的收盘位置是 1 或 0。

### 2. 破底站稳关键K（「黄色闪光」的核心触发）

| 参数 | 默认值 |
|---|---|
| 回看天数 | 120 |
| 跌幅百分比 | 30% |
| 均线周期 | 20 |
| 信号文字 / 颜色 | 「底」/ **#FDD835 黄色** |
| 订单流失衡平行线 | 每行 100 跳（日线）/ 2 跳（X 截图里的设置），价值区 70%，失衡 300%，最小堆叠 3 层 |
| 唯一警报 | **「三重条件信号」** |

推断：**黄色闪光** 很可能就是这个黄色「底」字（警报名直接叫「三重条件信号」）。三重条件从参数看是：① 120 日内从高点跌幅 ≥ 30%；② 与 20 日均线的关系（大概率是收盘重新站上 MA20，或 MA20 拐头）；③ 「破底站稳」本身——先创出新低，再收回。订单流部分只负责在信号附近画「多头失衡堆叠」平行线，作为支撑参考，而且有一整套「被后续 K 线吞没就作废、相邻信号按中点分地盘」的去重规则。

### 3. 流动性区域 / Liquidity identification

| 参数 | 默认值 | 含义 |
|---|---|---|
| 枢轴长度 | 10 | 左右各 10 根确认高低点 |
| 量能算法 | 原版 = 均量/σ；标准 Z = (量-均值)/σ | 只保留成交量够强的枢轴 |
| 强度过滤 | 原版 1/2/3，Z 值 0.5/1/2 | |
| 量能统计长度 | 500 | |
| 结构信号 | 最小跌幅 40%；上下枢轴最大间隔 20 根；第 2 根合格 K 出信号；有效期 20 根 | 「先高后低、大幅下跌、然后企稳」 |

区域被价格扫过就改为虚线并标「流动性已抓取」。抄底结构 = 放量枢轴高点到放量枢轴低点跌幅 ≥ 40%，两者相隔不超过 20 根，之后第 2 根「合格 K」给「流动性反转」。澳弘电子（605058）示例图上，信号出现在 2026-07 底部附近，随后两个月从 23 涨到 60。

### 4. 筹码结构（订单流版）

参数揭示了它不是同花顺那种「三角分布」筹码，而是一个**带锁仓识别的成本分布**：处理 1000 根、400 个价格档；「检查筹码稳定性 20 天」「稳定筹码最小占比 0.5%」；主力分析 15 天、大单 = 2 倍均量、集中度 5 区间 ≥ 20%；主导力量强/中/弱 = 0.6/0.3/0.1；流通股可选「A 股口径」或「自由流通」。订单流叠加 POC、买失衡（绿）、卖失衡（紫）。信息窗格输出：3/5/10/20 日筹码亏损比例、盈利比例、90%/70% 成本区间、区间重叠度、120 天内稳定筹码占比、稳定价格区间、主导力量强度、大单占比。

小红书白皮书封面写明方法是「**衰减换手模型** + 保留率过滤 + 订单流集成 + 主导力量反推」。[封面](../%E5%9B%BE%E5%83%8F/xiaohongshu/card-20.webp)

| 参数 | 默认值 |
|---|---|
| 闭环长度 N | 120 |
| 信号臂数 K / 总臂数 M | 6 / 30 |
| 白化（高阶臂加权） | 开 |
| 门槛统计回看 / 进门倍数 / 出门倍数 / 最低回波 | 200 / 1.5 / 0.5 / 3 dB |

### 6. 流动性热力图 Pro（HVN 状态机）

最值得借鉴的是 **HVN 簇状态机**：

```
吸筹簇（金黄）  ──收盘上穿上沿，连续 2 根确认──▶  铁底支撑（翠绿）
      │                                              │
      │                                 回踩不破 = 顺势低吸观察点
      ▼
跌破下沿 - 0.15 ATR 缓冲垫 ──▶ 跌破观察期（橙红，宽限 3 根）
      │                     │
      │          宽限期内收回 ──▶ 🔥 黄金坑强撑（Spring，高胜率拐点）
      ▼
  3 根内收不回 ──▶ 确认截断（暗灰），护盾停止延伸，执行风控
```

HVN 簇的定义参数：14 根滚动窗口、连续 ≥ 2 层高亮、最多 4 层、价格标尺步长 0.1 ATR、单层累积量 ≥ 3.2 倍均量。热度计算：Delta 加成权重 0.45，时间留存率 0.95（指数衰减），大 K 线冲破后单条热力当场截断、残留 8%，再叠加三类共振加分（日/周高低收 0.4、VWAP 0.35、波段拐点与整数关口 0.45）。K 线内最大量价位（Bar POC）的净量超过 1.65 倍均值时画蓝/玫红圆点。

### 7. 30%PBD

盘整框（蜡烛法 / ADX < 15 / 可视范围 ≥ 20 根）+ 框内多空量占比 + 200 根 Volume Profile（POC/VAH/VAL）+ 突破后延伸方块。作者自己写明：基础思路来自德国交易员 **Patrick Nill**；**只用盘整框和 Volume Profile 时回测胜率低、容易亏损**，必须加流动性热图、流动性区域、鲸鱼检查来过滤 VAH/VAL。小红书那条 307%「2 届世界赛冠军策略」说的就是这件事。

## 四、整体逻辑：一个「主力行为周期」状态机

把 36 个工具放回同一条时间线，他的体系其实只回答一件事：**这只票的大资金处于哪个阶段**。

```
 下跌出清        潜伏吸筹         洗盘/挖坑          点火启动           拉升            高位派发
 跌幅≥30~40%  → 低位+量枯+卖压 → 破底/假跌破 →   破底站稳「底」  → 青蛙动量    → POC 高位
 亏损日识别      衰竭+Delta背离    黄金坑/Spring      HVN 转铁底         资金趋势       + Delta 转负
 绝望见底        吸筹效率/筹码锁仓  暴力洗盘/砸盘B     雷达起爆/放量      高点吸收突破   狂热见顶
                                                                                    ↓
                          全程：大盘 + 个股双暴跌 → 崩盘刹车，信号归零
```

- 「位置与成本」层告诉他**哪里有支撑和压力**（筹码、HVN、流动性池、价值区）。
- 「主力行为」层告诉他**大资金现在在干什么**（吸 / 洗 / 拉 / 出）。
- 「触发」层只在前两层同意时给一个**可执行的 K 线**。
- 他交易的票几乎都是先跌 30% 以上、底部放量吸筹、再出现关键 K 的小盘股。

## 五、他的实际买卖节奏（从 7 只股票 56 处 B/S 标记看）

数据来自 [08 号核查](../08_%E5%8A%A0%E5%AF%86%E8%B4%A6%E6%88%B7%E4%B8%8E%E8%82%A1%E7%A5%A8%E4%BA%A4%E6%98%93%E5%8E%86%E5%8F%B2%E8%A1%A5%E6%9F%A5.md)：

| 标的 | 买入 | 卖出 | 节奏 |
|---|---|---|---|
| 南京化纤 600889 | 2024-10-17 | 2024-12-04 至 12-06 三笔 | 底部 1 笔进，连板后 3 天分批出 |
| 时空科技 605178 | 2025-09-22 | 2025-10-31 至 11-14 六笔 | 1 笔进，6 笔分批出 |
| 胜通能源 001331 | 2025-09-23 | 2025-12-29 至 2026-01-13 七笔 | 1 笔进，持有 3 个多月，7 笔出 |
| 红宝丽 002165 | 2025-03-26 至 04-25 九笔 | — | 底部区间分批买，含一次 T |
| 莲花控股 600186 | 2026-03-09 至 05-28 十二笔 | 2026-06-18、06-24 | 底部长时间分批吸，翻倍后「出本」 |
| 时代万恒 600241 | 2026-08-24 | 2026-10-12 至 10-22 六笔 | 1 笔进，分 6 笔出 |

规律很清楚：

1. **只在下跌后的底部区间买**，要么一次进，要么在 1–3 个月里分批吸。
2. **不止损式频繁换股**，持有 1.5–4 个月。
3. **卖出永远分批**，集中在急拉段的高潮附近（连板、放量）。「翻倍出本」= 涨一倍时卖掉本金对应的仓位，剩下的利润仓随便拿。
4. 公开的都是赢的单子。亏损单、止损单、没涨的单子一张都没有，这是看任何晒单都必须先扣掉的偏差。

## 六、对「每年本金翻倍」要打的折扣

- [01 号核查](../01_%E6%88%90%E4%BA%A4%E4%B8%8E%E5%B9%B4%E5%BA%A6%E6%94%B6%E7%9B%8A%E6%A0%B8%E6%9F%A5.md) 已经说明：没有连续账户权益、出入金、完整成交，**任何一年的收益都无法验证**。
- 2025 年终视频的标题是「每月翻倍股的 **bs 复现流程**」：先挑出每个月已经翻倍的股票，再用工具在图上复现买卖点。这是**事后复现**，不是事前预测。任何一套足够多的指标都能在已知赢家上「复现」出漂亮的 B/S。
- 「AI 交易系统进化图谱」写的是「亿万次对抗演化，仅保留胜率最高的策略基因」。没有样本外检验时，这种搜索几乎必然选出过拟合的策略。
- 他自己在 30%PBD 说明里承认，单用盘整框 + VP **回测胜率低、容易亏**。这句反倒是整份公开材料里最有价值的诚实信息：单个指标不行，要靠多层过滤。

结论：值得学的是**他的结构化思路**（行为周期状态机、多层确认、订单流数据降级、带迟滞和宽限期的状态机、分批出本），而不是相信某个参数组合能年年翻倍。我们的系统要在自己的数据上、按事前规则、扣掉成本后验证，见 [03 号文档](03_%E9%AA%8C%E8%AF%81%E6%96%B9%E6%B3%95%E4%B8%8E%E6%94%B6%E7%9B%8A%E9%A2%84%E6%9C%9F.md)。
