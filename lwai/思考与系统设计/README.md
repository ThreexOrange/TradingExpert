## 结论先看

1. **老王公开的只是 36 个工具里的 8 个**。GitHub issue 里一张他本人视角的截图列出了全部 36 个（含私密），7 个邀请制指标的发布页还公开了全部输入参数和警报文案，等于半张设计图。
2. **他的体系是一个「主力行为周期」状态机**：深跌出清 → 潜伏吸筹 → 洗盘挖坑 → 关键 K 点火 → 拉升 → 高位派发，外加大盘刹车。越新的工具越依赖真实订单流（逐价位主动买卖量）。「黄色闪光」很可能就是「破底站稳关键 K」的黄色「底」字（警报名为「三重条件信号」）。
3. **最值得借鉴的工程设计**：多身份综合分的权重结构、HVN 簇「吸筹 → 铁底 / 跌破观察 → 黄金坑 / 截断」状态机、订单流数据的三级降级、带迟滞的自适应门槛、分批「翻倍出本」。
4. **用日线数据检验的结果不好**：411 只股票、12 年，我们按他的思路定义的「破底站稳」「单阳不破」「实体谱雷达起爆」在扣成本后都**跑输市场**（20 日超额约 −1% 到 −3%，t 值显著为负）。A 股日线 K 线实体在统计上接近白噪声。他自己也承认单用形态和 Volume Profile 回测胜率低。
5. 所以优势如果存在，只可能来自**日线里没有的信息**（真实主动买卖、大单、筹码换手、题材资金）和**退出纪律**（拿住翻倍股）。下一步应该先拿 Tushare 的分单资金流（`moneyflow`）检验「破底处有大单吸收」能否把负超额扭正，同时测退出规则。
6. 「每年本金翻倍」目前**无法验证**：没有连续账户记录；年终视频是对已知翻倍股「复现」买卖点，属于事后拟合；公开晒单只有赢的单子。

## 怎么复现原型结果

```bash
cd lwai/思考与系统设计/code
python3 lwai_lab.py null                                  # 雷达回波零假设 vs F 分布
python3 lwai_lab.py fetch --cache /tmp/ycache --n 400     # 随机抽 A 股，Yahoo 日线
python3 lwai_lab.py study --cache /tmp/ycache --out result.md
python3 regime_check.py /tmp/ycache                       # 大盘环境切分与收益右尾
```

依赖 numpy、pandas。抽样用固定随机种子，但 Yahoo 数据会更新，数字会有小幅差异。

## 需要你决定或提供的

- **Tushare token**：H1（大单资金流）和模块 B（筹码换手）都需要。有了就能做第二轮检验。
- **YouTube 大纲截图**：重点是「3NB」「黄色闪光」「主力操盘进度 6 阶段」「仓位与止损」四件事。
- **资金规模和交易周期**：决定模块 G 的仓位上限、流动性门槛，以及要不要做 SmartVWAP 那样的分批建仓。
