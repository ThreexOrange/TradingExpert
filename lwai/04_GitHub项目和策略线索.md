## 公开技术线索

- README 描述盘后或延时行情、本地量化分析、Pine 指标、逐笔聚合的 K 线、订单流足迹和云地双模指标。以上是项目说明和功能演示。
- 维护者把自用研究方向概括为 A 股主力时机与价格分析，点名主力识别工具包、黄色闪光法。覆盖波段结构、RVOL、VWAP、Volume Profile、筹码和流动性热图。其回复提到相关腾讯视频小范围使用，公开搜索未定位该视频原址。[维护者回复](https://github.com/eggwong2/LWAI-trade/issues/2#issuecomment-6169885690)
- TradingView 的筹码结构订单流脚本说明也出现「黄色闪光专属」。它是公开描述、仅限受邀使用的指标。[脚本发布页](https://cn.tradingview.com/script/prnCA9VW/)
