# 威科夫基础速查

**说明**：《威科夫 2.0》默认读者已经学过作者前作《威科夫深度方法论》，书中直接使用下面这些术语。本文件是通用的威科夫方法知识，用于对照阅读，**不是这本书的内容**；具体判断仍以书中强调的背景与接受 / 拒绝为准。

## 三大定律

- **供求定律**：需求大于供应价格上涨，反之下跌，平衡则横盘。
- **因果定律**：趋势（结果）的幅度与之前累积 / 派发（原因）的规模相关；原因越大，结果越大。
- **努力与结果定律**：成交量（努力）与价格变化（结果）应该一致；不一致（大量却不动、无量却大动）提示可能转折。

## 累积结构的事件（中文译名按本书用法）

| 事件 | 英文 | 含义 |
|---|---|---|
| 初步支撑 | PS | 下跌中第一次明显的买盘出现 |
| 抛售高潮 | SC | 恐慌性抛售，放量长阴，常留下长下影 |
| 自然反弹 | AR | 抛压耗尽后的反弹，其高点常定义区间上沿（小溪） |
| 二次测试 | ST | 回到 SC 区域测试，通常缩量 |
| 弹簧效应 / 震仓 | Spring / Shakeout | 跌破区间下沿后迅速收回，清洗弱手；常是最佳买点之一（C 阶段） |
| 测试 | Test | 对弹簧效应低点的低量回测 |
| 强势信号 | SOS | 放量大阳线，突破或接近区间上沿 |
| 最后支撑点 | LPS | 突破后的回踩低点，缩量 |
| 回踩小溪 / 冰层 | BU / BUEC | 突破上沿后回到上沿（小溪）上方测试 |

**小溪（Creek）**：累积区间的上沿阻力；**冰层（Ice）**：派发区间的下沿支撑。

## 派发结构的事件

| 事件 | 英文 | 含义 |
|---|---|---|
| 初步供应 | PSY | 上涨中第一次明显的卖压 |
| 买入高潮 | BC | 放量冲高，常留长上影 |
| 自然回落 | AR | 高潮后的回落，其低点定义区间下沿（冰层） |
| 二次测试 | ST | 回到 BC 区域测试 |
| 上冲回落 | UT / UTAD | 突破区间上沿后迅速跌回；UTAD 出现在派发后段（C 阶段） |
| 弱势信号 | SOW | 放量大阴线，跌破或接近冰层 |
| 最后供应点 | LPSY | 跌破后的反弹高点，缩量 |

## 阶段

| 阶段 | 内容 |
|---|---|
| A | 停止之前的趋势（PS / SC / AR / ST，或 PSY / BC / AR / ST） |
| B | 建立原因：区间内反复测试，大资金吸筹或派发 |
| C | 测试：弹簧效应或上冲回落，检验剩余的供应或需求 |
| D | 区间内趋势：SOS / LPS 或 SOW / LPSY，价格向区间一端推进 |
| E | 离开区间，趋势展开 |

本书把 A 到 E 阶段对应到拍卖理论的「趋势 → 停止 → 震荡 → 转换」四个环节，并强调：**对结构和事件的确认都是事后的**，交易时要依靠价值区域、接受与拒绝，以及关键价位上的订单流触发。
