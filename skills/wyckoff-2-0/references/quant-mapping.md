# 量化映射与检验

把书中的规则写成只用当时已知数据的定义。书中原规则标「书」，为了能计算补的参数标「补」。`scripts/volume_profile.py` 实现了成交量分布部分；足迹图部分可以直接用 `skills/order-flow-trading/scripts/footprint.py`。

## 成交量分布的计算

| 元素 | 定义 | 来源 |
|---|---|---|
| 分布 | 价格分成固定行高的价位；有逐笔数据时按成交价累加，只有 K 线时把每根 K 线的成交量**均匀摊到它的最高最低价之间**（近似） | 补（K 线摊派是常用近似） |
| POC | 成交量最大的价位；并列时取离区间中点近的 | 书 / 补 |
| 价值区域 | 从 POC 出发，每次比较上方两行与下方两行的成交量，加入较大的一侧，直到累计 ≥ 70% | 市场轮廓的通用算法；书中说约 68–70% |
| HVN / LVN | 平滑后的分布（3 行移动平均）的局部峰 / 谷；峰高 ≥ 分布均值的 1.3 倍算 HVN，谷低 ≤ 0.5 倍算 LVN | 补 |
| 未回补 POC | 已完成会话的 POC，之后任何一根 K 线的最高最低价都没碰到过 | 书（定义）；补（「碰到」= 区间包含） |
| VWAP 与标准差带 | 会话开始累计的 Σ(典型价 × 量) / Σ量；标准差为成交量加权的价格离差 | 书 |
| P / b 型 | 分布 POC 在区间上 1/3（P）或下 1/3（b），且 POC 一侧的成交量占比 ≥ 60% | 补 |
| 强势 / 弱势 K 线 | 收盘在 K 线上 1/3（下 1/3）、幅度 ≥ 1.2 × ATR、成交量 ≥ 前 20 根中位数的 1.2 倍 | 书（三个特征）；补（阈值） |

## 可以直接检验的规则（都还没检验过）

1. **80% 规则**（书，源自市场轮廓）：前一会话的价值区域为参照；价格在 VA 外开盘或运行后重新进入 VA，并在 VA 内停留 2 根 K 线（补），记为事件；统计在当天（或接下来 N 根 K 线）内到达 VA 另一端的比例。对照组：同样位置但没有重新进入的情况，以及随机时点在 VA 内时到达两端的比例。书中说约 80%，没有给统计。
2. **未回补 POC 的回补概率**：每个会话结束后的 POC，在之后 1、5、20 个会话内被触及的比例；对照：同样距离的随机价位被触及的比例（距离要匹配，否则只是在测距离）。
3. **POC 移动后的延续 / 反转**：按书中五条反转规则和两条延续规则写成条件，统计之后的方向。
4. **强势 K 线止损单入场**：在价值区边界、结构边界出现强势 / 弱势 K 线后，用 K 线极值外的止损单入场，止损放在 K 线另一端，目标价值区另一端或前一个 HVN；统计 R 倍数，与同位置的随机方向比较。
5. **结构的成交量特征**：累积中成交量逐渐下降、派发中出现异常高量——作为区分两者的特征，检验它对突破方向的预测力。

数据：加密可以用币安 1 分钟或 5 分钟 K 线（免费）画日内分布，用逐笔成交（aggTrades）画精确分布和足迹；24 小时市场要先定「会话」（例如 UTC 0 点切分）。外汇用对应期货的数据才有真实成交量（书中建议）。

检验纪律：规则和参数写定再跑；分时期报告；所有事件入账；与匹配的对照组比较，而不是只看「赚钱的比例」。

## 已有检验结果

- 3xOrangeTradingTheory 仓库里，流动性区域的「扫过区域后当根收回」（即弹簧效应 / 上冲回落的最简版本，没有成交量分布和订单流确认）在币安全部永续日线上没有超额。这只说明**单独的假突破**不够，不说明书中「背景 + 价位 + 订单流触发」的完整流程没用。
- 老王流动性热力图 Pro 的黄金坑（跌破 HVN 吸筹簇下沿、3 根内收回）是本书弹簧效应 + 测试的量化版本，研究计划里列为待检验项。
