# 威科夫 2.0 交易框架（第 5–6 章）

## 理论要点

1. 讨论市场逻辑的前提是完整的框架：**三大定律**（供求、因果、努力与结果）以及**累积和派发**。
2. **因果**：要有上升趋势（结果），先要有累积（原因）；下降趋势前要有派发。
3. **背景最重要**：用当前价格行为推演未来可能的路径。结构形式各不相同，本质一样；要理解分形——小结构组成大结构。
4. 每个走势以特定方式完成或失败，都留下线索，是评估强弱的客观依据。
5. **努力与结果**是判断一致或分歧的最好逻辑：把有利于每一方的行为加起来，看哪一方更可能控制。
6. 威科夫的累积和派发就是拍卖理论的平衡区，趋势就是失衡。另加一条原则：**市场为了促成交易，总会回到以前的活跃区域**，可以用来找止盈。

## 背景：区间还是趋势

**区间背景**：

- **区间边界**：趋势停止后进入平衡，在结构两侧找反转。威科夫：在 C 阶段失败突破处入场——上方找上冲回落（UTAD），下方找弹簧效应（Spring），反转后价格会去区间另一端。成交量分布：在 VAH 做空、VAL 做多，被拒绝后很可能到另一侧。
- **区间内部**：区间足够宽、有获利空间时，可以在 C 阶段测试后、D 阶段区间内趋势中入场；同时要有足够的目标空间和盈亏比。宽分布里最近的 HVN 决定短期方向：价格在它上方偏多，下方偏空（视为派发）。
- 区间内没有一方完全控制，仓位要适度；假突破后按 80% 规则做反转。

**趋势背景**：

- **价值区边界**：失衡发生后先判断是不是失败突破（重新回到价值区）。有效突破就找顺势机会：威科夫是 D 阶段突破后的测试；纯成交量分布是离开价值区后在同一价位的测试。
- **区分累积和派发（判断突破真假）**：
  1. 失败的突破：本质是在寻找流动性；失败得越深越确定；局部的假突破不算，要等整体失败。
  2. 突破或失败突破时的价格和成交量：大阳 / 大阴线伴随高成交量说明被控制；突破处流动性充足，可能出现高量和长影线，不能一开始就判定为假突破，因为吸收也有这些特征，关键看之后。
  3. 突破后的反应：价格在区间外横盘被接受；或 POC 移到新区域、之后的时段形成新的交易区；**价格不重新回到价值区是最后的确认**。突破后不应耗费太多时间，应出现新的 POC 并开始走趋势。
- **远离价值区**：价格在找新的平衡，等回调测试再入场。倾向于顺着累积 / 派发的方向交易，**直到出现反方向的结构，或价格失去最后一个价值区**（上涨中，当前价下方最后一个支撑趋势的 HVN）。理想情况是在某个价位（如周 VWAP）上方形成一个小结构。

## 交易区域与关键价位

基础逻辑对所有背景和周期都一样：**确定交易区域和关键价位 → 等失衡触发 → 入场**。

- 日内：前一交易日分布作背景，当日分布作决策。长线：前一周或数周、数月的复合分布和更大周期 VWAP。结构交易：按结构及其关键节点画分布。已完成的分布比发展中的更可靠。
- **区间两侧**：结构高低点的潜在假突破（激进入场），假突破后的测试（保守入场）；VA 两侧的反转，有时与结构两侧重合。
- **区间内部**：HVN（离价格还远就等它到）；LVN（用覆盖整个区间的分布找）；当日 VWAP 和 POC（日内）或包含几天的 VWAP 和 POC（结构交易）——这些价位决定控制权，等有效突破后第一次测试入场；强势突破有时不留测试，资金会更激进地入场。
- **价值区边界（突破后）**：被打破结构的价位（经典的突破后再测试，回到小溪或冰层，本质是 LVN）；VA 两侧；区间 POC（突破后回调的最后关键价位，离得太远就单独考虑，因为那时价格已经回到价值区，按反转失败原则处理）。
- **远离价值区（趋势中回调）**：上一交易日的关键位（VA 两侧、VWAP、POC）；周 VWAP；上一段快速行情的 POC；LVN（用复合分布、快速行情分布、前几日分布分别找）。回撤幅度与之前动量成比例；第一个价位太近就看下一个。优先多个价位的汇合区。

## 交易计划与触发

- 做多时希望关键价位在当前价下方，等价格回来；做空反之。价格还在不利一侧时，用「两步走」：等它先突破到交易区上方并完成测试再入场。
- 用「如果 X，那么 Y」的方式持续验证，两个方向都考虑，必要时迅速改变看法。例：倾向向上突破、等突破测试买入，结果价格重新回到区间并强烈拒绝（上冲回落），就转而找做空。
- **触发 K 线**：强势 K 线 = 收在上三分之一、幅度大、相对放量；弱势 K 线对称。订单流只用两组概念：反转（吸收 + 主动）、延续（控制 + 测试）。

## 入场

- 用**止损单**（条件市价单）：强势 K 线后在其高点上方买入、弱势 K 线后在低点下方卖出，确认延续才成交。能避开大部分「开盘强势、收盘反转」的 K 线内吸收陷阱。
- 也可以 K 线收完后市价入场；看到足迹上积极的订单时不必等收线；或在可能的回撤处用限价单。
- 作者不建议用限价单直接在预期的测试位埋单：那是在赌测试一定会发生；测试可能根本不出现、价格直接继续下跌。正确做法是价格到达「应该反转」的区域后，再看是否出现上涨失衡。

## 止损

- 放在重要 K 线和结构之后：机构主动进入的区域，价格不利时他们会捍卫头寸。
- 最好放在重要价位或交易区域的另一侧；第一个要找的是 **LVN**（V 形反转会保护头寸；如果价格快速穿过 LVN，就会触发止损，这也是正确的离场）。
- 例：潜在弹簧效应后出现强势 K 线，止损买单在其上方入场；止损放在触发 K 线下方或整个结构下方，前面有 VWAP、VAL（同时是 LVN）等价位保护。弱势 K 线做空时，止损可放在触发 K 线高点之上、反转形成的最高点之上，或 POC 另一侧；要权衡距离与盈亏比。
- 价位有时在很窄范围汇聚（胜算更大），有时不重合，要评估哪里值得承担风险。

## 止盈

1. 情绪 K 线（没有其他依据时）；
2. A 阶段停止之前趋势的位置；
3. 价格转折处的流动性区域（前高前低）；
4. **之前的高成交量区域**：失衡之后市场会去找反向交易者，所以会回到之前的 HVN；新的交易区比旧的更有吸引力。HVN 是区域，具体价位用它的 POC。
5. **动态 POC**：当天某一时刻的 POC，不论是否是最终 POC，只用还没被测试过的。
6. **未回补 POC**：之前交易日最终 POC 中还没被测试过的，几乎只用作目标；作者说有统计显示前几日的 POC 在之后被测试的概率很高（书中未给出来源）。

到第一目标可以全部或部分离场，至少把止损移到保本。

## 高级管理

**按背景入场**：

- 优先满足结构发展和背景：因果（显著的原因已经建立）；整体成交量特征（**累积中成交量逐渐下降，派发中出现高量或异常值**）。
- 依次寻找三个关键行为：**假突破**（结构高低点，级别越大、越猛越好）→ **突破**（有意图的长 K 线、放量，把价格带到结构另一端）→ **测试**（K 线短、曲折、成交量低于突破；测试后不重新进入区间）。
- 不能盯盘时：要么放弃；要么在背景已明确有利时先入一部分（金字塔式），触发条件出现后再补足。没有触发 K 线时止损放在结构的某个位置。

**结构的成交量特征**：结构关键位置的成交量越大，对后续走势的影响越大（因果）。快速拉升应伴随高成交量（机构在场）；没有高量的「拉升」可能只是修正或随后背离。累积后越过小溪，回踩小溪边缘时不应放量；不及预期就可能是假突破、回到区间。如果越过小溪后形成一个小派发结构并测试小溪边缘，说明短期空头控制；作者的做法是等价格突破这个小派发结构、站上它的 POC，再找入场点。

**威科夫价位还是成交量分布价位？** 两者都创造流动性区域、都可能出现失衡；把所有可交易价位列出来，让价格确认哪个更重要。例：向上突破时可参考小溪、阻力变支撑、VAH，依次观察触发。如果价格找的是 VAH 而不是小溪，可以在 VAH 触发入场，也可以等价格重新站上关键位置后再入场，或分两次入场（先在 VAH 入一部分，再次触发时补满）。

## 案例中的要点（第 6 章）

- 欧元 / 美元：A 阶段（抛售高潮、自然反弹、二次测试）→ B 阶段上冲回落测试高点 → 第一天分布的 LVN 反复成为拒绝区 → 弹簧效应加测试 → 足迹 Delta 由 −240 变 +183 → 控制与测试 → POC 抬升后继续上行、测试周 VWAP。目标：之前的 HVN（也曾是动态 POC），其次是前高。
- 英镑 / 美元：前一周分布作背景；价格在 POC 上方、在 VAH、周 VWAP、累积结构上沿的汇合区等触发；足迹出现主动买（Delta +685、+793 和失衡）后，用突破处的买入止损单入场，止损在方框内最低 K 线下，目标是未回补 POC。
- 标普迷你：跌破前一日 VAL 本应做空，但价格重新进入 VA、底部假突破后上行；稍低于 VAL 的 VWAP 汇合处不是最佳买点，站上 VAL 后 5 分钟图上出现吸收、高于均量的上涨失衡、短期最大 Delta，入场；目标 VA 另一端，也与之前 POC 区域相交。
- 美元 / 加元：价格在前一日 VA 内横向，按区间原则；在 VAL 精确测试（两日小结构的弹簧效应）后出现主动买失衡入场，按 80% 规则目标 VAH，到达后至少移止损到保本。
- 英镑 / 美元（下跌背景）：派发结构 → 价格回到被打破的价值区测试 → 足迹上最后一根上涨 K 线放量、买方失衡却涨不动（吸收）→ 大负 Delta 的主动卖出 → 弱势 K 线确认。止盈在之前的 POC。
- 欧元 / 美元（反转失败）：前一日上破 VAL 失败、按反转原则找空，但在交易价位足迹出现反转——持空就平仓，长线背景下甚至可以反手做多；信号冲突时降低杠杆（例如用差价合约而不是期货）。
