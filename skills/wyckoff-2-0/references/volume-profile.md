# 成交量分布（Volume Profile）

成交量分布是 Steidlmayer 1985 年为芝加哥期货交易所设计的市场轮廓（Market Profile）的变体：把成交量按价格累加成水平直方图，用来找交易者最感兴趣的区域，并判断价格在当前区域被接受还是被拒绝。**市场有记忆，但多是短期记忆**：新的交易区比旧的重要，失衡后首先要看的是最近的平衡区。

## 组成

| 元素 | 含义与用法 |
|---|---|
| 价值区域（VA） | 以 POC 为起点向两侧扩展，包含约 68–70% 成交量（约一个标准差）的区间，被视为「接受区」；其外约 30% 为「拒绝区」 |
| VAH / VAL | 价值区高点 / 低点，平衡时的阻力 / 支撑。价值区宽 = 参与者多、各自都能成交；窄 = 交易不活跃 |
| 极端点 | 分布的最高、最低价，关键参考 |
| 完成的拍卖 | 价格向极端运动时成交量递减，末端是低成交量点，出现明显拒绝（极端处只有 1 个 TPO）。说明那个方向没人感兴趣了 |
| 未完成的拍卖 | 极端处出现高成交量节点（≥ 2 个 TPO），价格以后很可能回来测试。判断不了时按「完成」处理；未完成的拍卖常和 VAH / VAL 重合 |
| POC | 成交量最大的价位，买卖双方共同接受的基准，也是计算 VA 的起点；常是机构累积头寸的地方。价格在 POC 上方 = 买方控制，下方 = 卖方控制。POC 是高成交量节点，但高成交量节点不一定是 POC |
| VWAP | 一段时间内的成交量加权平均价，机构用来评估执行质量；价格在 VWAP 下买是低于成本。用日、周、月 VWAP 和 ±1、±2 个标准差带作参考；平衡市里有效，趋势市里 VWAP 不再代表价值 |
| HVN（高成交量节点） | 分布的峰，平衡区，像磁铁吸引价格回来，适合做**目标** |
| LVN（低成交量节点） | 分布的谷，失衡或被拒绝的价位。价格到这里要么 **V 形反转**（看法没变，回到原价值区）、要么**快速穿过**（看法已变，止损和动量单推动，大阳大阴线放量）。适合找**入场**和放**止损** |

## 类型

- **固定范围**：任意选定一段（整段趋势、整个结构），不随时间更新。下跌趋势中画整段，看价格在 POC 等价位反弹时是否还参与趋势；震荡结构中用来定 POC 和 VA 两侧，找突破后的测试点。
- **日内（会话）分布**：每天从开盘到收盘，随时间更新。短线交易者看当天和前几天的分布；例如上涨后的震荡，等价格回到 POC；价格回调守在前一日 VA 上方，期待上方继续测试。
- **复合分布**：把多日合并（Donald Jones 提出），固定（上周、上月、一年）或可变（随图表可见范围更新）。用于宏观背景：在长周期 HVN 上设目标；在潜在累积结构附近找大级别 LVN，期待那里出现弹簧效应。
- **垂直 vs 水平成交量**：传统成交量是时间维度（市场活不活跃），成交量分布是价格维度（哪些价位重要），互为补充。
- **成交量分布 vs 市场轮廓**：市场轮廓按每 30 分钟一个字母（TPO）累计时间，成交量分布累计成交量；成交量最大的价位不一定是耗时最长的价位。作者认为当今市场更应看成交量；初始平衡（开盘第一小时区间）越窄，当天越可能走趋势。

## 形状

- 不要指望分布总是 D 型（平衡）。市场轮廓对交易日的分类（正常日、趋势日、双分布日等）都是盘后确认，Steidlmayer 本人也承认不能用前一天的形状持续预测下一天。
- **P 型**：先上涨、再在高位震荡。是多头特征，后续可能是派发或再累积。**标准 P 型**（失衡在左：先涨后横）才有交易意义，可以接下来的趋势；**镜像 P 型**（先横后跌）时机已晚。长期下跌后出现标准 P 型，提示下跌即将结束。
- **b 型**：先下跌、再在低位震荡。空头特征，后续可能是累积或再派发；长期下跌背景下是参与下跌的好区域。长期上涨后出现 b 型，可能是上涨结束。
- **价值认知的变化**：下跌中价值区逐级降低，突然出现 **b 接 P（bP）**，可能是下跌结束、甚至上涨开始，默认是累积；上涨后出现 **P 接 b（Pb）**，默认是派发。不必等完美形态：只要失衡被拒绝、价格回到价值区，失衡何时发生并不重要。

## 用途

1. **识别结构**：结构末端常不清楚，用整个结构的分布找 VAH、VAL；结构的高低点应是 LVN（拒绝处）；结构的小溪、冰层常与 VAH、VAL 重合。分布范围应从震荡开始覆盖到失衡发生前；突破后在之前累积 / 派发的价位上找测试。
2. **判断偏向**：始终倾向于**最后一个 HVN** 所在一侧的方向：价格在它上方 = 多头控制；跌破它才准备做空；下跌中只有重新站上最后一个 HVN 才考虑做多。这个 HVN 不必是 POC，要随趋势不断更新。
3. **选择交易价位**：做多希望所有参考价位都在当前价下方（阻力最小方向）；看价格和 VWAP、POC 的关系：VWAP 与 POC 接近说明平衡，只做两端反转；多头控制时价格应在两者上方，空头控制时在两者下方。日内用前一日和当日价位，长线用周 POC 和周 VWAP（消除短期波动）。
4. **趋势健康度**：上涨中价值区（含 POC）逐级抬高 = 价格被新价位接受；价值区开始重叠、出现反向移动 = 动能减弱，可能进入区间。
5. **POC 移动**（日内为主，逻辑适用于各周期）：POC 移动后，到底是延续还是反转，要两手准备。
   - 有利于**反转**：之前的趋势健康，POC 移动后没有继续原方向；横盘消耗时间（越久越可能反转）；之后出现反方向的快速移动（市场特征改变）；第一次交易机会在价值区一端（下方做多、上方做空），第二次在 POC。
   - 有利于**延续**：POC 移动后价格以一定速度继续原方向、耗时少；等触发信号入场。
   - 每个价格行为都要被后续确认或否定：POC 移动但价格最后远离了它，仍视为拒绝。价格、时间、成交量三者一致时，价值认知才真正改变。
6. **仓位管理**：入场看 VWAP、POC、VAH / VAL；止损放在之前被拒绝的区域（LVN）之后，希望入场点前面有尽量多的价位保护；止盈找之前流动性充足的 HVN。

## 价值区域交易原则

| 原则 | 条件 | 做法 |
|---|---|---|
| **区间** | 价格在价值区内，条件没变 | 在 VA 两侧找反转，低买高卖；最低目标 POC，较高目标穿越整个 VA 到另一侧。多个价位（如周 VWAP 与前一周期 POC）重合处胜率最高 |
| **反转（80% 规则）** | 价格在 VA 外开盘或突破，又成功回到 VA 内 | 很可能走到 VA 另一侧。来自市场轮廓的经验规则：重新进入后约 80% 的情况会到达另一端（书中没有统计依据） |
| **延续** | 价格试图进入价值区但在两侧或关键价位被拒绝，或离开 VA 后被接受 | 沿突破方向找突破后的回踩测试入场；开盘在 VAH 之上说明买方有能力把价格推离前收，回到 VAH 附近是买点 |
| **反转失败** | 价格进入 VA，但在 POC 被强烈拒绝 | 取消反转计划；若到达 VA 末端，按延续原则；若最终有效突破 POC，反转计划重新激活，目标 VA 另一端 |
