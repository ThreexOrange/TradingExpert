# 威科夫 2.0（结构 + 成交量分布 + 订单流）

以独立研究员和交易员身份工作。本 Skill 是读书笔记与方法提炼，用自己的话重写，不含原书正文和图表。原书例子多是外汇期货、标普迷你期货的日内图；用到加密、个股或日线以上要重新检验。

## 三层分工

1. **威科夫结构给背景**：现在是区间（平衡）还是趋势（失衡）？是累积还是派发？哪一方在控制？依据是三大定律（供求、因果、努力与结果）、事件和阶段。
2. **成交量分布给价位**：在哪里交易。价值区域上下沿、POC、VWAP（日、周）、高成交量节点（目标、磁铁）、低成交量节点（拒绝、止损保护、假突破处）。
3. **订单流给触发**：在这些价位上，足迹图出现吸收后接主动（反转），或控制后接测试（延续），才入场。

作者反复强调：**订单流脱离背景没有意义**（同一笔成交可能是新开仓、止损或止盈，看不出意图）；**结构识别是事后的**，交易要靠价值区域和价格对它的接受与拒绝。

## 工作流程

1. **定背景**：区间还是趋势；在区间里是边界还是内部；在趋势里是在价值区边界附近还是已经远离。
2. **画分布**：日内交易用前一日分布做背景、当日分布做决策；中长线用周、月或覆盖整个结构的复合分布；结构交易者按结构范围画固定区间分布。已完成的分布比正在形成的更可靠。
3. **列出交易价位**：结构两端（假突破）、小溪 / 冰层、VAH / VAL、POC、日 / 周 VWAP、上一段快速行情的 POC、LVN、未回补 POC。几个价位汇合处优先。
4. **写好「如果……那么……」**：例如「如果突破小溪，就等测试关键位后找买点；如果是假突破，就等反方向的测试找空点」。两个方向都要准备。
5. **等触发**：价格到交易价位后，看足迹图：反转用「吸收 + 主动」，延续用「控制 + 测试」；或者出现强势 / 弱势 K 线（大幅度、收在上 / 下三分之一、相对放量）。
6. **入场**：用止损单（条件市价单）在强势 K 线高点上方买入 / 弱势 K 线低点下方卖出，确认延续再成交；作者不建议用限价单赌测试一定发生。
7. **止损**：放在触发 K 线或整个结构之外，最好有 LVN、VWAP、VAL 等价位在前面「保护」。
8. **目标**：价值区域另一端、前一个 HVN / POC、未回补 POC、前高前低流动性、A 阶段停止行为的位置；到第一目标至少把止损移到保本。
9. **持续验证**：每个价格行为都要被后续走势确认或否定；判断错了就改，不要守着最初的偏好。

## 和 3xOrange Advanced System 的关系

- 老王的流动性热力图 Pro（HVN 吸筹簇 → 铁底 / 跌破观察 → 黄金坑）、30%PBD（盘整框 + 成交量分布 POC/VAH/VAL）、筹码结构都建立在成交量分布之上；黄金坑就是威科夫的弹簧效应（Spring）加测试。
- **已经检验过、没通过的**：单独的假突破（扫低点收回）在加密日线上没有超额。见 [量化映射与检验](references/quant-mapping.md#已有检验结果)。
- **可以检验、还没检验的**：价值区域的 80% 规则、POC 移动后的延续 / 反转规则、强势 K 线止损单入场、未回补 POC 的回补概率。规则和模板在量化映射里。

## 归属与限制

- 80% 规则来自市场轮廓（Market Profile）的经验说法，书中没有给出统计；「前几日 POC 在之后被测试的概率很高」书中提到有统计，但没有给出来源和数字。
- 书中一切形态都强调灵活解读，理想形态很少出现；把它写成代码时会丢掉部分判断，结论只适用于写定的那一版规则。
- 威科夫基础事件部分是通用知识，不是这本书的内容，已在对应文件中标明。
