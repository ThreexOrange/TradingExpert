# 量化映射与检验

把书中的规则写成只用当时已知数据的定义。书中原规则标「书」，为了能计算补的参数标「补」。`scripts/pa_signals.py` 按下表实现。

## 可计算定义

| 规则 | 定义 | 来源 |
|---|---|---|
| Pinbar（看多） | 下影线 `min(O,C) − L ≥ 2/3 × (H − L)` | 书 |
| Pinbar（看空） | 上影线 `H − max(O,C) ≥ 2/3 × (H − L)` | 书 |
| 合并形态 | 连续 2 根（吞没）或 3 根（双星）合成一根 OHLC 后满足 Pinbar；吞没还要求最后一根实体包住前一根实体、方向相反；顺方向 K 线数 ≤ 反方向 | 书（合并原则只在 1H 合 4H 时用，这里统一套用为补） |
| 拐点 | 左右各 `n` 根内的最高 / 最低点，**第 n 根之后才算确认**（不回填）；拐点后至少 4 根反向运行或幅度 ≥ 2 × ATR 才算明显 | 书（4 根）；补（n = 5、2 ATR） |
| 关键位 | 把明显拐点按 0.5 × ATR 的距离聚类成水平区域；强度 = 拐点数 + 拐点级别 + 近期权重 | 书（三条强弱规则）；补（聚类距离和权重） |
| 必要条件 1：在关键位 | 信号影线末端距最近关键位 ≤ 0.5 × ATR，或刺穿关键位 | 补（距离） |
| 必要条件 2：明显高低点 | 信号低点是最近 10 根最低（看多），且前 3 根收盘逐步走低 | 书（3 根）；补（10 根窗口） |
| 细节 1：明显 | 信号幅度 ≥ 1 × ATR(14) | 补 |
| 细节 2：假突破 | 影线刺穿关键位、收盘回到关键位另一侧 | 书 |
| 细节 3：左眼 | 实体在前一根最高最低之内，且幅度 > 前一根 | 书 |
| 细节 4：顺大级别趋势 | 收盘在 100 根均线之上且均线 20 根前更低（看多）；看空对称 | 补（书中用「回调不超过 61.8%」，需要人工判断大级别波段） |
| 细节 5：盈亏比 | 突破入场价到下一个关键位的距离 ÷ 信号全长 ≥ 1.5 | 书 |
| 可交易 | 两个必要条件都满足，细节 ≥ 2 | 书 |

## 已有检验结果

- 在 3xOrangeTradingTheory 仓库里，用枢轴高低点（左右各 10 根）加量能过滤画出流动性区域，测试「扫过区域后当根收回」，也就是假突破。在币安全部 USDT 永续的日线上（2020-08 到 2026-10），扣掉同一天全市场的平均收益后，10 天和 30 天的超额都不高于零，按时期拆开也一样。这说明**单靠假突破**不够。
- 还没有检验过的是**完整的 2+5 评分**：Pinbar 形态、左眼、关键位强度、盈亏比过滤叠加在一起。

## 检验模板（写定再跑，只跑一次）

1. **市场与周期**：币安 USDT 永续，4 小时和日线分开；含已下架币；只用当时成交额足够的币。
2. **信号**：`pa_signals.py` 的可交易信号（2+2 以上），参数用上表默认值，一次定死。
3. **入场**：突破信号入场（下一根 K 线突破信号极值时成交，含跳空按开盘价成交）；有效期 3 根，过期未触发作废。
4. **止损**：信号影线外；**目标**：下一个关键位；另加 20 根时间止损。
5. **结果**：每笔 R 倍数、胜率、平均 R；扣手续费和滑点；与同一时刻、同方向、同止损止盈距离的随机入场比较；分 2020–2022 和 2023–2026 两段。
6. **分层**：按满足的细节数（2、3、4、5）分组看是否单调变好，这能检验评分本身有没有用。
7. 全部信号入账，包括未触发和过期的。

## 和老王（LWAI）体系的对应

| 本书概念 | 老王体系里的对应 |
|---|---|
| 关键位（拐点水平线） | 流动性区域、前高流动性、筹码峰 |
| 假突破 + Pinbar | 2B、「抓取前高流动性」后反向、黄金坑（跌破后收回） |
| 明显高低点 + 趋势中回调 | 1B / 2B / 3B 的位置划分 |
| 突破入场、回调 50% 入场 | 他的建仓分批（1B 少、2B 少、3B 多） |
| 金字塔加仓 | 他的右侧加仓曲线（按固定浮盈比例加），风险比本书温和 |
