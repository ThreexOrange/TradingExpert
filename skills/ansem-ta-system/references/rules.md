# Ansem TA 法则全文 v1.0

目录：§1 账户 · §2 阶段 · §3 选强 · §4 画位 · §5 四形态 · §6 止损 · §7 止盈 · §8 指标 · §9 执行与复盘 · §10 禁止事项

标签含义：【A】原话，【A+】归纳，【补】补全参数。来源 ID 对应 [quotes.md](quotes.md)。

术语：**HTF** = 周线或日线；**LTF** = 4H 或 1H，只用来放失效位；**收盘** = 交易所 UTC 00:00 的日线收盘，周线指周一 00:00 UTC 的收盘。

---

## §1 账户与仓位

1. 现货、合约、链上分成三个账户，盈亏分开记。【A Q-TF1】
2. 大多数人应该只做现货；合约只用于 S3 做空和 S4 对冲。【A T-PAIR】
3. 核心仓和主动仓分开。2023 年他的自述是 70/30；用户自己设定，默认 70/30。【A I1-70 / 补】
4. 本金小的时候，先选一个计价资产（BTC、ETH 或 SOL），所有盈利都滚回这个资产，用它衡量是否跑赢。【A Q-1K】
5. 单笔仓位：`数量 = 主动账户净值 × r ÷ (入场价 − 失效价)`，r 默认 1%，同时最多 3 笔，同一板块最多 1 笔。【补】
6. 失效距离超过 15%（山寨）或 8%（BTC、ETH）时，降仓或放弃。不能为了凑仓位把止损挪近、离开结构位。【补，依据 Q-INV "wont be risking it down to $55k"】

## §2 市场阶段

每周日收盘后判断一次。依据只用两样：BTC 的周线和日线结构；主流山寨的 ALT/BTC 比值（选 3–5 个，或者用 OTHERS/BTC 代替）。【A+ Q-RH、C2、Q-TF2】

| 阶段 | 判定 | 怎么做 |
| --- | --- | --- |
| **R1 BTC 领涨（S1）** | BTC 周线收在区间上方或创新高，多数 ALT/BTC 在走低 | 主动仓做 BTC 或最强的大币，可以不碰山寨【A "being sidelined during S1 is ok"】。山寨只做率先收复 ATH 的那一个。 |
| **R2 BTC 横盘、山寨轮动（S2）** | BTC 在日线区间内整理（C2 的例子是 60.8k–80k），有 ALT/BTC 比值突破自己的区间 | 必须在场【A "being sidelined during S2 is not"】。对大幅回撤后横盘数月的山寨，在区间高点设提醒，按 S1、S4 做。 |
| **R3 风险出清** | BTC 日线收盘跌破"最后一个主要支撑"，周线也确认 | 现货主动仓减到一半以下；只做 S3 的空方，或者等 S2 的收复信号。 |

补充：
- 山寨相对 BTC 的跑赢期通常是 4–6 个月；同一领涨者市值涨了 10 倍以上之后，留意新的领涨者，把利润轮动过去。【A Q-TF1、Q-TF2】
- 阶段判断有分歧时，按低一档处理：拿不准是 R2 还是 R1，就按 R1 做。【补】

## §3 选强（纯技术）

**候选**必须满足下面至少 3 条：

1. 从前高回撤至少 50%，之后横盘至少 8 周（或 60 根日线）。【A Q-RH "retraced significantly / sideways for several months"，N-NEAR "100 day+"；数字是补】
2. 比值图（ALT/BTC；L1 生态币看 ALT/L1，ETH 生态看 ALT/ETH）不再创新低，或者已经突破比值区间。【A N-Q4、L-SOL】
3. 大盘急跌时跌得少，并且比大盘先收复急跌前的价位。【A Q-STR】
4. 同一批里第一个收复 ATH，或者从底部算涨幅最大。【A Q-HYPE】
5. 板块的主资产刚刚完成 S1 突破，这个币是它的高 Beta 跟涨币（例：SOL 突破后去看 BONK）。【A I1】

**否决**，满足任一条就不做：

- 比值图回测前高后走出更低高点。【A Q-ZEC】
- 近 30 天已经涨了 5 倍以上，并且远离任何关键位（只能追高）。【补，依据 Q-1K、T-PARA】
- 日均成交额太低，计划仓位超过日成交额的 1%。【补】

观察池最多 10 个，周末确定之后一周内不加不减。【补】

## §4 画位

顺序：周线 → 日线 → 比值图 → 只给当前计划画 LTF。

| 位 | 定义 | 用途 |
| --- | --- | --- |
| 区间高点 / 低点 | 横盘期间至少被触及 2 次的水平区，画成一个区而不是一条线，区宽不超过 1 倍日线 ATR14【补】 | S1 触发、S2 刺穿 |
| 前高 / ATH | 周线上的最高收盘和最高影线，两者都标 | S1 第一目标、价格发现的起点 |
| 周线关键位 | 至少两次转换过支撑和阻力角色的周线水平【A+ Q-W1 "key weekly resistance"】 | S3 |
| 收复位 | 被日线收盘跌破的旧支撑 | S2 |
| 倾向失效区 | 更高一级的支撑区（例：HYPE 25–30、WIF 0.75–0.80）【A Q-HYPE、Q-WIF】 | 决定还做不做多，和单笔止损分开 |
| LTF 整理区 | 突破或跌破前，4H 或 1H 上的最后一段横盘 | S3 空单失效位【A Q-W1】 |

画完在区间高点、收复位和失效位上设价格提醒，然后离开图表。【A Q-RH "alerts set on range highs"、Q-TF1】

## §5 四个标准形态

不属于这四类的走势一律不交易。所有触发都按收盘判定。

### S1 区间突破 / 价格发现（主形态，做多）

- **前提**：处于 R1 或 R2；标的通过 §3；区间持续至少 60 根日线或 8 根周线。【A Q-RH、N-NEAR、I1】
- **触发**：日线收盘高于区间高点的上沿。周线收盘高于上沿是更强的版本，仓位可以按满额。【A I1、Q-HYPE "high timeframe strength above"】
- **入场**，二选一，交易卡上写清楚用哪种：
  - S1a 收盘追入：触发后下一根日线开盘入场；触发日收盘离区间上沿超过 1 倍 ATR 时不追，改成等 S1b。【补】
  - S1b 回踩确认：触发后 10 根日线内回踩到区间上沿 ±0.5 ATR，并且收盘没有回到区间内，就在这根收盘入场。等不到就记为未触发。【补】
- **失效**：日线收盘回到区间上沿之下，并且下一根日线收盘也没有站回，就离场（突破失败）。硬止损放在回踩低点或突破那根 K 线的低点下方 0.25 ATR，二者取较低者。【A+ / 补】
- **目标**：T1 = 周线前高或 ATH；突破区间以上已经没有前高时，直接按 §7.2 进入价格发现跟踪。【A Q-HYPE "ATH price discovery"】

### S2 收复 / 假跌破（做多）

- **前提**：一个 §4 定义的关键支撑或区间低点被刺穿，在"有意义的周期"（日线，或者至少 4H）上收盘跌破，然后又收盘站回。【A Q-WIF "reclaim on meaningful TF"、B1】
- **触发**：跌破之后 5 根日线内，有一根日线收盘重新站上这个位。比值图版本：ALT/BTC 收复前低，可以作为美元价格收复的确认。【补 / A L-SOL】
- **入场**：触发那根收盘时入场，或者等回踩收复位不破再入场。
- **失效**：刺穿段的最低点下方，也就是"当日或这一段的低点"。【A Q-INV】收复之后再次收盘跌破收复位，立即离场，不等止损。【A L-SOL "cutting if it cant reclaim"】
- **目标**：T1 = 区间中轴，T2 = 区间高点。在区间高点按 S1 重新评估。【A+】
- **不做**：5 根日线内没有收复，或者处于 R3 而且 BTC 本身还没收复。【补】

### S3 高周期关键位二元判定（多空双向，主要用于 BTC 和大币）

- **前提**：价格已经回到一个周线关键位附近。在这个位置附近不预判、不追单；如果别处有更好的做多机会，宁可去做那个。【A Q-W1 "not looking for longs here as i think there are better things to long"】
- **两种情景必须同时写下**【A Q-W1、C1】：
  - 多：周线（或日线）收盘高于关键位 X，目标是上方下一个周线位。
  - 空：跌破关键位下方的 LTF 整理区下沿 Y，即"ltf bearish"，目标是下方下一个主要支撑。空单失效位 = 跌破前那段 LTF 整理区的上沿。
- **入场**：多单在收盘确认后入场；空单在 4H 收盘跌破 Y 后入场，或者等反抽 Y 不过时入场。
- **失效**：错了就平仓，不死扛。另一方向的条件成立时可以反手。【A C-W 平空，以及随后 Q-INV 转多】
- **目标**：下一个 HTF 位，到达后按 §7.1 处理。

### S4 比值轮动 / 配对

- **现货版**：预期比值 A/B 会上涨（ALT/BTC 突破区间，或者 S2 收复），就把 B 换成 A。没有新增风险，只是换了持仓资产。【A T-PAIR】
- **合约版**：山寨被打穿、正在筑底，而大币仍在区间里震荡时，做多山寨，同时做空等名义价值的 BTC 或 ETH 对冲。【A T-PAIR】
- **入场**：比值图按 S1 或 S2 的规则触发。
- **失效**：比值图收盘回到区间内，或者跌破刺穿低点。
- **退出 / 换回**：比值急涨（大约 5–10 倍）之后回测前高，形成更低高点，就换回 BTC 或基准资产，或者把利润转到新的领涨者。预期山寨会跑输时，整体轮动回 BTC。【A Q-ZEC、T-ROT、Q-TF2】

## §6 止损 / 失效总表

| 情形 | 失效位 | 来源 |
| --- | --- | --- |
| S1 突破 | 收盘回到区间内并且下一根没站回；硬止损在回踩低点下方 0.25 ATR | A+ / 补 |
| S2 收复 | 刺穿段最低点；收复后再次收盘跌破收复位就立即走 | A Q-INV、L-SOL |
| S3 多 | 当日或这一段的低点，不往下扩 | A Q-INV |
| S3 空 | 跌破前 LTF 整理区的上沿 | A Q-W1 |
| S4 比值 | 比值图上的同类结构位 | A+ |
| 方向倾向 | 更高一级支撑区收盘失守，就不再新开多单 | A Q-HYPE、Q-WIF、B1 |

规则：

1. 交易止损和方向倾向是两层。止损打掉之后，只要倾向区还在，可以按 S2 再进场；倾向区失守之后，停止做多这个标的。【A+】
2. 失效位只能往有利方向移动，不能往远处挪。【A Q-INV】
3. HTF 的失效按收盘判定。同时在区外挂一个灾难硬止损（失效位再往外 1 倍日线 ATR），防止跳空或盯不了盘。【补】
4. 同一标的连续两次失效之后，这个标的停做 2 周。【补】

## §7 止盈 / 离场总表

1. **到达下一个 HTF 位**（T1）：减仓 1/3 到 1/2，剩下的止损移到入场价，或者移到最近一个日线更高低点的下方。【A 位到位目标 / 补比例】
2. **价格发现或趋势中**：不按浮盈或固定 R 倍数止盈。只在日线收盘跌破最近一个摆动低点时离场；周线收盘跌破最近一个周线摆动低点时，清掉核心仓。【A Q-PNL；跟踪方式是补】
3. **抛物线**：先用趋势线确认价格已经进入抛物线（斜率越来越陡）。第三次推高并突破上方阻力趋势线时，认为接近尾声，分 2–3 批卖出，不等跌破结构。【A T-PARA】
4. **短时间涨出几倍**（动量交易）：例如 30 天内达到 3 倍，至少先收回本金和一半利润。【A Q-1K；数字是补】
5. **比值图走出更低高点**，或者领涨者涨了 10 倍以上：减仓，把利润转到新的领涨者或计价资产。【A Q-ZEC、Q-TF2】
6. **时间**：山寨跑赢期进入第 4 个月后，止损收紧到日线前一个摆动低点；第 6 个月以后不再新开同一主题的山寨多单。【A Q-TF1；执行方式是补】
7. **反向情景成立**（S3 的另一边）：全部平仓，按规则决定是否反手。【A C-W】

## §8 指标

本人公开发言里能看到的工具：水平位和区间、日线和周线收盘、HH/HL 结构、趋势线（用于抛物线）、比值图。没有证据表明他固定依赖某个振荡指标。所以：

- 必需的只有价格结构和收盘。
- 可选的【补】：日线 ATR14，只用来定区宽、缓冲和"是否追高"；突破当天成交量高于 20 日中位数的 1.5 倍，作为加分项，不作为必需条件。
- EMA、RSI、Ichimoku 可以作为用户自己的过滤器另立版本（例如 v1.0-EMA），不能当成 Ansem 的规则。

## §9 执行节奏与复盘

**每周（周日收盘后）**：判断阶段 → 更新观察池 → 画周线位 → 设提醒 → 写或更新交易卡。

**每日（UTC 00:00 日线收盘后，一次）**：处理触发的提醒 → 用收盘确认 → 执行或撤单 → 移动止损和止盈。盘中只处理灾难止损和已经挂好的单。【A Q-TF1】

**日志**：每笔交易一张卡（[模板](../assets/trade-card.md)）。触发但没成交的、被否决的、过期的都要记。【A Q-J】

**统计**：笔数、胜率、平均盈利 R、平均亏损 R、期望 R（所有交易净 R 的均值）、最大回撤、最长连亏，按 S1–S4 和 R1–R3 分组。至少 30 笔之后才调参数，每次只改一个，改完记版本号（v1.1……）。【补】

**回放回测**：从连续的历史区间里按时间顺序推进，只看已经收盘的 K 线；所有候选都要记录，不能从涨幅榜反推样本。手续费和滑点按真实情况扣除。

## §10 禁止事项

- 在 15m 或 5m 上做方向决定，或者因为盘中波动修改已经写好的计划。【A Q-TF1】
- 在区间中部开仓。
- 扩大止损，或者在亏损仓位上加仓（加仓只能在新的 S1、S2 触发时做）。【A Q-INV】
- 因为"浮盈很多"就在趋势中途全部卖掉（例外：§7.3 和 §7.4）。【A Q-PNL】
- 把一次喊单后的上涨当作这套规则有效的证据。
