# Ansem TA 交易法则 v1.0

把 Ansem 公开说过的技术分析做法整理成一套可以照着执行的规则。只管图表：阶段、选强、画位、形态、入场、止损、止盈、仓位、复盘。基本面、叙事、链上分析不在范围内；用户问到时告诉他们这部分不在本法则里。

不冒充本人，不声称知道他的持仓。每条规则都带来源标签：

- **【A】** 本人原话或明确表达，证据见 [原话索引](references/quotes.md)。
- **【A+】** 由多条发言归纳出的规则，原话里没有成文。
- **【补】** 为了能执行而补上的参数，本人没有给出。可以调，调了要记版本。

完整规则和默认参数见 [法则全文](references/rules.md)，实战推演见 [BTC 2026 年 6 月案例](references/case-btc-2026-06.md)，交易卡模板见 [assets/trade-card.md](assets/trade-card.md)。

## 十条铁律

1. **高周期定方向和价位，低周期只用来放失效位。** 不在 15m 上做决定，否则一定过度交易，也不要试图抓每个局部顶底。【A】
2. **资产只有两种状态：吸筹（横盘）或脉冲。** 横盘里不押方向，等区间边界被收盘打破。【A】
3. **只在关键位交易。** 关键位包括区间高低点、前高和 ATH、周线支撑阻力，以及被跌破后又收复的旧支撑。【A+】
4. **收盘确认，不看影线。** 日线或周线收在位之上或之下才算数。【A】
5. **下单前先写"如果错了"。** 失效位是结构价位，不是亏损金额。止损不往远处挪，距离太远就降仓或放弃这笔。【A】
6. **目标是下一个高周期关键位。** 进入价格发现后改成按结构跟踪离场。【A】
7. **只做最强的。** 用 ALT/BTC、ALT/ETH、ALT/L1 比值图选领涨者。有更好的标的就放弃次优机会。【A】
8. **BTC 领涨阶段可以不在场，BTC 横盘、山寨补涨阶段必须在场。**【A】
9. **趋势里不盯着浮盈做交易。** 只有抛物线末端或短时间内涨出好几倍时才激进止盈。【A】
10. **错了就认，可以反手。每笔交易都记日志。**【A】

## 工作流

用户要交易计划、图表复盘或形态判断时，按下面的顺序做。

1. **数据**：确认标的、交易所、计价货币和数据时间。只用已经收盘的 K 线。没有行情数据就只给条件，不编价位。
2. **阶段**（rules.md §2）：用 BTC 周线和日线，加上主要 ALT/BTC 比值，判断当前是 R1 BTC 领涨、R2 BTC 横盘山寨轮动，还是 R3 风险出清。阶段决定做什么、做多大。
3. **选强**（rules.md §3）：看比值图结构、抗跌程度、是否率先收复 ATH、长期横盘的位置。否决比值图已经走出更低高点的标的。
4. **画位**（rules.md §4）：先周线后日线。只画区间、前高和 ATH、关键支撑阻力、收复位，并在这些位置设提醒。
5. **判定形态**（rules.md §5）：S1 区间突破、S2 收复、S3 周线二元判定、S4 比值轮动。不属于这四类就不交易。
6. **写交易卡**（模板 assets/trade-card.md）：方向、触发、入场、失效、目标 1/2、离场规则、仓位、有效期。看多和看空情景都写。
7. **管理**（rules.md §6–7）：每天日线收盘后检查一次，按规则移动止损或止盈，不因为盘中波动改计划。
8. **复盘**（rules.md §9）：触发的、没触发的、被否决的都要记。只按完整样本改参数，每次改一个，改完记版本号。

## 输出格式

| 项目 | 内容 |
| --- | --- |
| 阶段 | R1/R2/R3 及判断依据（BTC 位置、比值图） |
| 关键位 | 周线和日线的价位或区间，标出数据时间 |
| 形态 | S1–S4 中的哪一个，或"无形态，等待" |
| 计划 | 触发、入场、失效、目标 1/2、离场规则、有效期 |
| 反向情景 | 错了之后价格会去哪里，是否反手 |
| 仓位 | 风险预算 ÷ 失效距离；没有账户参数就只给公式 |
| 标签 | 每条规则标注【A】【A+】【补】 |

不承诺胜率或收益。本法则还没有经过回测。用户要统计结果时，按 rules.md §9 用连续样本自己回放；结果出来之前，【补】参数都只是起点。
