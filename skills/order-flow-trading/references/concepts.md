# 概念与定义

记号：一根 K 线内，价位 p 上的主动卖量记为 `bid(p)`（以买一价成交、卖方主动），主动买量记为 `ask(p)`（以卖一价成交、买方主动）。`t` 为最小跳动。足迹图左列是 `bid`，右列是 `ask`。

## 基本元素

| 概念 | 定义 | 读法 |
|---|---|---|
| 跳（tick） | 最小价格变动单位 | 止损、失衡比较都以跳为单位 |
| 主动型买方 / 卖方 | 用市价单立刻成交的一方；推动价格 | 趋势由主动单推动，限价单本身不形成趋势 |
| 被动型买方 / 卖方 | 挂限价单等人来成交的一方 | 支撑阻力的本质是某价位有大量被动挂单；被动方常是大资金 |
| Delta | 一根 K 线内 `Σask − Σbid` | 上涨 K 线通常 Delta 为正；Delta 与 K 线方向相反要警惕 |
| Max / Min Delta | K 线形成过程中累计 Delta 到过的最大、最小值 | 类似 Delta 的「最高价、最低价」 |
| 累计 Delta | 当日各 K 线 Delta 的累加；可再除以当日累计成交量 | 看全天主动方向 |
| POC | 一根 K 线内成交量（bid+ask）最大的价位 | 位置比数值重要，见下 |
| 价值区间 | 包含约 70% 成交量的价格区间（一天或一段） | 价格离开价值区间需要大单推动 |

Delta 的大小要和时间周期、交易时段对照：1 分钟图、夜盘、早盘清淡时段 Delta 天然小；判断是否「接近零」要用 `|Delta| / 成交量`，不要用绝对值。

## POC 在 K 线中的位置

- 大多数时候 POC 在 K 线中部，市场中性。
- **POC 在底部、收盘在 POC 之上**：底部有人承接，偏多。
- **POC 在顶部、收盘在低位**：顶部大量主动买没能推高价格，被动卖方更强，偏空。
- 震荡市里 POC 长时间不动，说明那里是公认的「合理价」；POC 突然跑到 K 线极端，常是大资金的痕迹。

## 失衡（Imbalance）

按拍卖逻辑做**斜对角**比较（主动买方吃的是上一档的卖一，主动卖方砸的是下一档的买一）：

- **需求失衡（买方失衡）**：`ask(p) ≥ k × bid(p − t)`
- **供应失衡（卖方失衡）**：`bid(p) ≥ k × ask(p + t)`
- 书中常用 `k = 3`（300%），可选 250%、400%。也可以设为同价位比较，但默认用斜对角。
- 分母为 0 时要设最低成交量门槛，否则 1 比 0 也会被判为失衡（书中未给，属本 Skill 的工程补充）。

## 堆积失衡（Stacked imbalance）

- **连续 3 个及以上价位**出现同方向失衡。
- 买方堆积区 = 潜在支撑带，卖方堆积区 = 潜在阻力带。逻辑：在这片价格急切主动成交的人，价格回来时还会再出现。
- 失效：后续 K 线**收盘**跌破支撑带（或站上阻力带）；也可改用最低 / 最高价判定。
- 可信度看成交量：突破吸收区间、伴随放量形成的堆积区更可信；趋势中只是对手方缩量造成的堆积（主动单本身不大）可信度低。

## 大单与微单（顶 / 底两档的成交量比）

只比较 K 线**最极端的两个价位**：

- 顶部比率 = `ask(次高价) / ask(最高价)`
- 底部比率 = `bid(次低价) / bid(最低价)`
- 书中插件的做法：上涨 K 线算顶部比率，下跌 K 线算底部比率。分析高低点时两端都看。

| 形态 | 条件（书中阈值） | 含义 |
|---|---|---|
| **大单**（Large prints） | 比率 < 0.699，理想 < 0.5；且极端价位成交量的**绝对值**明显放大 | 极端价位异常放量却没有延续：有人在那里接住了全部主动单（被动大资金），价格短期难以越过 |
| **微单**（Single / small prints） | 比率 > 28，数值越大越强 | 极端价位几乎没人追了：推动方力气耗尽 |

- 比率要和绝对量一起看。例如底部 5 手、上一档 2 手，比率很「好看」，但量太小，没有意义。
- 大单之后再出现微单（先放量被接住，回来再试时没人追），是作者最看重的组合之一。

## 被套交易者（Trapped traders）

- **被套多头**：K 线**顶部**出现需求失衡或主动买量显著放大，但价格没有继续上涨，收在低位或随后下跌。最后追高的人被套，他们的止损会加速下跌。
- **被套空头**：K 线**底部**出现供应失衡或主动卖量显著放大，但价格没跌下去，收在高位。
- 与大单的区别：大单看的是顶 / 底两档的**相对比**；被套看的是极端价位**绝对量**放大和随后的反向走势。两者可以同时出现。
- 作者认为它通常是短线反转机会，不一定是大趋势结束。

## 吸收（Absorption）

- 价格在一段区间里来回，主动买和主动卖**都很大**，但 `|Delta| / 成交量` 很低。
- 与普通盘整的区别在成交量：盘整可能只是没人交易（假期、数据公布前）；吸收是双方大量换手。
- 吸收结束、一方压倒另一方时，价格离开区间，是低风险入场点。
- 收盘前最后几分钟的「吸收」多是平仓和按收盘价执行的指令，不代表新供需。

## 主动出击（Initiative）与回应（Responsive）

- **多头主动出击**：大额主动买单把价格推出价值区间上沿；**空头主动出击**同理向下。
- 散户没有能力把价格推出价值区间；能做到的通常是大资金。
- 突破时如果看不到强推动力，就要观察对手方是否「回应」——把价格拉回原价值区间。

## 订单流背离

在普通背离（新高但 Delta 为负 / 新低但 Delta 为正）基础上，作者加了收盘方向的过滤：

- **看跌背离**：价格创新高（相对前一根），Delta 为负，**且收盘 < 开盘**。
- **看涨背离**：价格创新低，Delta 为正，**且收盘 > 开盘**。
- 只作参考，需要别的信号确认；震荡中会频繁出现。

## 趋势为什么会停

- 上涨停止：买方不愿再在更高价买；买方力气耗尽；卖方压倒买方。
- 下跌停止：卖方不愿再卖；卖方存货卖完；卖方被买方吞没。
- 价格从低点反弹的原因：空头平仓，或多头建仓。从高点下跌：多头止盈，或空头建仓。
- 下跌往往比上涨快：下跌不一定要卖方多强，只要承接的买单少就够了。
