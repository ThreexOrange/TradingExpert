# 量化映射与检验

把书中的读盘概念变成可以计算、可以事先写定规则检验的定义。书中阈值标「书」，本 Skill 为了能计算而补的参数标「补」。

## 数据

| 市场 | 能做到的粒度 | 来源 |
|---|---|---|
| 加密（币安 U 本位永续） | **价位级足迹**：每笔聚合成交带价格、数量和主动方向 | `data.binance.vision/data/futures/um/daily/aggTrades/<SYMBOL>/<SYMBOL>-aggTrades-<YYYY-MM-DD>.zip`，免费；字段 `is_buyer_maker = true` 表示买方是挂单方、**卖方主动**（计入 bid），`false` 计入 ask |
| 加密 | K 线级 Delta | K 线自带 `taker_buy_volume`：Delta = 2 × taker_buy_volume − volume。只有整根 K 线的买卖差，算不出 POC、失衡、大单微单 |
| 美股 | 需要逐笔成交 + 主动方向 | Databento 等付费数据带主动方向；没有方向时要用报价推断（Lee–Ready），误差大。FINRA 场外每日数据只有场外总量和卖空量，不是足迹 |
| A 股 / 国内期货 | 快照（Level-1 约 3 秒一次） | 原书中译本用国内数据商的 tick 构建足迹；快照数据只能近似 |

## 可计算定义（`scripts/footprint.py` 已实现）

| 信号 | 定义 | 参数 |
|---|---|---|
| 价位聚合 | 价格按 `tick × rows_per_level` 取整到价位 | 补：行高按品种设 |
| Delta、Max/Min Delta | 按成交时间顺序累计 ask − bid | — |
| POC 位置 | `(POC − low) / (high − low)`；< 1/3 为底部，> 2/3 为顶部 | 补：三等分 |
| 斜对角失衡 | 买方：`ask(p) ≥ k·bid(p−1)`；卖方：`bid(p) ≥ k·ask(p+1)`；分子须 ≥ `min_vol` | 书：k = 3；补：min_vol |
| 堆积失衡 | 同方向失衡连续 ≥ 3 档，记录区间上下沿 | 书：3 档 |
| 顶部 / 底部比率 | `ask(次高)/ask(最高)`、`bid(次低)/bid(最低)`；分母为 0 时记为无穷大 | — |
| 大单 | 比率 < 0.699 且极端价位量 ≥ `big_mult` × 该 K 线每档平均量 | 书：0.699；补：big_mult |
| 微单 | 比率 > 28 | 书：28 |
| 被套多头 / 空头 | 顶部 2 档内有买方失衡（或顶部大单），且收盘位于 K 线下 1/3；底部对称 | 补：「下 1/3」 |
| 吸收 | `|Delta| / 成交量 ≤ 0.1` 且成交量 ≥ 过去 20 根中位数的 1.5 倍 | 补：两个阈值都是补的，书中只说「Delta 相对很低」 |
| 订单流背离 | 看跌：高点 > 前一根高点、Delta < 0、收盘 < 开盘；看涨对称 | 书 |
| 高质量多 / 空 | Delta > 0、收盘 > 开盘、ask 总量 ≥ `dom` × bid 总量（空头对称） | 补：dom = 1.5 |

所有信号只用这根 K 线收盘时已知的成交；堆积失衡区从形成的那根 K 线收盘起才可用，不回填。

## 已有检验结果

在 3xOrangeTradingTheory 仓库里，和订单流有关、已经事先写定规则检验过的（都没有通过）：

- **K 线级主动买卖**：3xOrange Advanced v1 在日线模型上加入小时线的主力痕迹（主动买卖差、吸收、大额成交等 24 个特征），没有增量；v0 日线模型（含主动买卖特征）选币排序优于等权，但没跑赢 BTC。作为妖币前奏特征时，主动买盘偏多同时提高翻倍和腰斩的概率（P09）。
- **流动性区域还原**：枢轴高低点 + 量能过滤画出的区域，扫单收回（假突破）在加密日线上扣掉同日全市场后没有超额。
- **美股场外订单流**（P10）：FINRA 每日场外成交、卖空占比的异常加高低点结构，没找到行情起点。

这些都是 K 线级或日级的汇总量。**本书核心的价位级信号还没有检验过**，这是下一步可以做、而且数据免费的方向。

## 检验模板（写定再跑，只跑一次）

1. **市场与样本**：例如币安成交额前 50 的 U 本位永续，某一时期的全部交易日（含已下架币）；15 或 30 分钟 K 线。
2. **背景过滤**（可选，但要事先写定）：只看价格位于 [关键价位清单](levels-context.md#关键价位清单) 某个价位附近（例如 0.3 × ATR 以内）的 K 线。
3. **信号**：从上表挑 1–3 个，参数用书中默认值，补充参数一次定死。
4. **入场与离场**：信号 K 线收盘后下一根开盘入场；止损在信号价位外 1–2 跳或信号 K 线极值外；目标为固定 R 倍数或下一个关键价位；加时间止损。
5. **结果**：每笔的 R 倍数、胜率、平均盈亏比；扣手续费和滑点（加密每边至少 0.04% 加点差）；与同一时刻随机方向、同样止损止盈的基准比较。
6. **分时期报告**，例如 2023 年和 2024–2025 年分开；两段都满足才算通过。
7. **记录所有信号**，包括没有入场的；不要在同一段数据上反复调阈值。

## 和老王（LWAI）工具的对应

- 他公开的「破底站稳关键 K」参数里有一组订单流设置：每行 2 跳、价值区 70%、失衡阈值 300%、**最小堆叠层数 3**，就是本书的斜对角失衡和堆积失衡。
- MMOF 的「高点吸收」要求 ≥ 3 格买方失衡；筹码结构订单流版用价值区 70%、失衡 300%。
- 课上的「主力吸收」「黄金坑（跌破后收回）」可以对应本书的吸收、被套空头和底部大单。
