# 最新发言与观点变化

## 检索与身份

1. 用户未指定时间时，先查最近 7 天，结果少则扩至 30 天。以用户时区报告截止时间；源站时区不明时保留原显示日期，不强行换算。
2. 从来源台账里的本人账号查主帖、回复、引用帖和长文；Substack Archive 没有新长文不能推断 X 没有更新。平台自述属于有日期的证据，其他同名账号未获交叉认证时只作线索；新认证出现时更新，不把旧平台清单写成永久事实。
3. 用带年份的日期检索和原帖 URL/ID 去重。警惕搜索返回去年同月旧帖、置顶帖及关联推荐。必要时用 X ID 内嵌时间作一致性检查：UTC 毫秒 = (整数 ID >> 22) + 1288834974657；它只能辅助核日期，不能证明作者、正文真实性或镜像完整性。取得可靠作者元数据时与数字 user ID `1940360837547565056` 核对，不同 ID 不归于该已确认账号；第三方档案的 ID 字段不能代替源站认证，缺元数据就标未核。台账日期统一写 UTC，需要时另注北京时间。
4. 先打开原帖，再核公司公告、电话会或监管资料。原页受限时，可读取合法公开镜像，但显式标“第三方镜像正文；原页未核”；只有摘要就标“摘要线索”。聚合站的多/空评分不是本人明确观点，多处复制不是独立确认。
5. 检查正文是否截断及是否带图表、视频、引用帖。未读的附件留空。来源冲突时记录冲突和可核验部分，不以数量投票。不要绕过付费墙、登录或访问控制。

## 证据台账

每条记录：原帖 URL/ID、作者、发帖时间及时区、事件时间、读取方式、可见范围、访问日期、标的、观点摘要、独立核验、待核点、与旧观点的差异、交易条件变化。

明确区分三层：**可核事实**（如公司披露）、**Serenity 主张**（含其转述与推断）、**本 Skill 判断**。管理层展望是带条件的前瞻表述，不是已实现收入。镜像里引述某 CEO 不能直接升级为公司事实。

动态记录放在来源台账，不把当期看多标的、目标价、融资余额或期限写死在核心工作流。每次仍须重新联网；历史快照不能代替当前验证。

## 差异与输出

对照同标的、同期限的旧观点，分类为强化 / 削弱 / 反转 / 重复 / 待核。区分长期产业判断、短期股票判断和产品选择，不能把长期看多翻译成今天买入，也不能把对增发不满翻译成产业逻辑失效。

用紧凑表格交付：日期、说了什么、与旧观点的差异、核验程度、对交易的含义。报告最新“可访问样本”的日期和覆盖缺口；未检索到不等于没有发言，不推断其当前持仓。只查发言时无需编造入场点位。

更新方法时，优先抽取跨标的适用的决策规则；单篇未核线索只记台账，不变成普遍定律。对风险监测，说明发生了什么、传导到哪些资产、是否改变此前方向、下一验证指标；重复旧消息不当成新风险。
