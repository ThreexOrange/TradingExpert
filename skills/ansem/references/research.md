# 研究方法：证据、时间、数学、执行与验证

公式、窗口和阈值都是研究工具，归属规则见 SKILL.md。

## 1. 证据与动作

从 @blknoiz06 原页和已核作者渠道追踪；展示名相同不验证身份，别名需交叉链接或原 ID 确认。保留原文、引用对象、回复、图片、撤销与后续。动作类型：idea、conditional_entry、self_reported_position、fill_record、add、reduce、exit、invalidate、celebration、watchlist。发帖时市价不是本人入场价，公开记录不等于完整账户。

优先原帖和长文、直接访谈，其次完整镜像，再次媒体解读；AI 摘要只找线索。图片必须实际打开：核交易所/产品、周期、线性或对数轴、时区、指标参数、真实 candle 与预测箭头。没读到就写没读到，不把媒体或 AI 的图像描述当识图。

## 2. 时间对齐

保存原帖、事件、图表截止和访问时间；统一 UTC，显示北京时间和 IANA 交易所时区。X ID 可推候选时间 `ms=(int(id)>>22)+1288834974657`，标 `id_derived_unconfirmed`，需原帖或可信导出核验；冲突时排除精确时点研究，日期粒度只给当日区间。

只用 `bar_close_time <= decision_time` 的已完成 bar；盘中数据要当时快照。信号在 bar 完成后产生，模拟用随后可成交报价。日/周 close_time 取真实 session，不给美股日线硬加 86400 秒。pivot 需要右侧 k 根时，第 i+k 根完成后才已知；最终 zigzag 端点和事后重画的区间都会泄露未来。

## 3. 识图与数据

线性轴两点校准 `P(y)=p1+(p2-p1)*(y-y1)/(y2-y1)`；对数轴对 ln P 做同样插值。像素误差 δy 传播为 ±δP，一个锚点不够。TradingView 横轴按已交易 bar 排列，美股隔夜/周末不能按墙钟插值。普通 volume 柱不能重建 volume profile。

核同一 venue、pair、价格类型；OHLC 合法、时间唯一、缺 bar、单位、拆股/除息、合约迁移。结构用当时未复权的可交易尺度，长期回报另标复权。跨资产只在共同已完成 session 比较，不前向填充周末股票价格制造领先。图上标原帖线、事前水平、信号和最早可执行时点，未来段分隔为复盘；无 OHLCV 不造 candle。

## 4. 技术数学

**波动与区间。** `TR=max(H-L,|H-C_prev|,|L-C_prev|)`，Wilder `ATR_t=((n-1)ATR_prev+TR_t)/n`，前 n 个 TR 均值作种子。优先作者事前画线；没有时 `U=max(H[t-N:t])`、`D=min(L[t-N:t])`，不含当前 bar。`W=U-D`、`q=(C-D)/W`、`W/ATR`；零分母记未知。`ER_N=|C_t-C_(t-N)|/Σ|ΔC|` 描述净位移效率，低 ER 不证明吸筹；压缩用短/长 realized vol 比和 ATR/C 历史百分位，宽区间不等于低波动。

**突破与回踩。** 冻结事前 U；`B=(C-U)/ATR`、实体 `|C-O|/(H-L)`、`CLV=(C-L)/(H-L)`、`RVOL=V/median(V_prev)`。预注册比较 ε=0/0.1/0.25 与收盘确认、次根保持、回踩确认；回踩用 `(L-U)/ATR`、`(C-U)/ATR`，定义等待和过期根数。

**假跌破与收复。** 水平 S：刺穿 `F=(S-L)/ATR`、收回 `(C-S)/ATR`、下影 `(min(O,C)-L)/(H-L)`。支撑区 [S_low,S_high] 要事前指定刺穿哪边、多久收回哪边、保持多久。状态机：等待 → 刺穿 → 收回 → 保持/回踩 → 失效；`τ_reclaim` 超 K 根记未确认，收回后再失守记反例。

**相对强弱与 Beta。** 比值 `R=P_a/P_b`；`RS_h=ln(P_a,t/P_a,t-h)-ln(P_b,t/P_b,t-h)`。绝对上涨而 RS<0 可能只是 Beta。事前 OLS `r_a=α+βr_b+e`，事件残差 `AR=r_a-(α̂+β̂r_b)` 不是可复制 Alpha。比值图上的结构（区间、收复、更低高点）按价格图同样处理，基准按 BTC/ETH/SOL 或 QQQ/SPY/行业 ETF 选。

**风险。** 方向 d∈{1,-1}，`RR=d(T-E)/(d(E-S))`，奖励和风险须为正；未知 S 不算 R。`Q=权益×风险比例/(|E-S|×每价格单位合约价值)`，再受杠杆、保证金、相关集中和深度限制。美元、%、ATR、R 分列；名义敞口、计划止损损失与压力跳空损失分列。

## 5. 市场与执行

**加密。** 核链/合约地址、venue/pool、quote、现货/永续/指数/标记价；查深度、FDV/流通、解锁、资金费/OI。转账不是买卖，局部强势不是全市场 altseason，提及代币不证明权益关系。

**美股。** 区分正股/ETF/期权/CFD/代币化映射；核 session、DST、盘前盘后与跳空，财报和稀释查 SEC/公司 IR。期权查到期、bid/ask、IV、乘数和指派，标的到目标不保证期权盈利。

**可跟随性。** 分开发帖前布局和读者发帖后执行；用延迟后真实报价、点差、费用、滑点、funding/借券。上涨可能来自市场 Beta 或发帖冲击，不自动证明 Alpha。本人撤销观点、价格失效和基本面反证分开记录。

## 6. 统计验证

**样本。** 预注册连续时期、市场、纳入标准、全部标的和删帖/不可读缺口；成功、失败、撤销、过期、未触发都保留。同一主题多帖归一个 cluster。时间顺序切开发/验证/留出，重叠持仓 purge/embargo；记全部试验次数，看过的留出集不再叫样本外。

**三种结果分开。** 观点方向（预定 horizon 回报、MFE/MAE）；独立模拟（信号后成交、费用、延迟、深度）；本人实际收益（需可靠成交和完整仓位，公开帖不够）。多头 `MFE=max(0,max(H)-E)`、`MAE=max(0,E-min(L))`，空头相反，除以事前风险距离得 R。

**路径。** 同一根同时触及止损和目标、又无更细数据时先按止损算并标路径不明；跳空止损按第一个可成交价。

**统计。** 初始风险 R0 冻结后不变。报独立 cluster 数、触发率、扣费均值/中位数/尾损、MFE/MAE、回撤、资金占用和基准；胜率附 Wilson 区间，收益按主题/时期 block bootstrap；数量不足不报显著性。事件研究的系数窗口在事件之前；发帖可能内生于走势，相关不推因果。

先列反证再分析；失败就修订条件或取消规则，不删失败、不改历史止损、不编动机。无连续案例和同源行情时，只给描述、可核算术、候选规则和缺口。合成数据和软件测试不是历史回测。

## 7. 脚本

```bash
python scripts/analyze_chart.py bars.csv --asof 2024-04-19T12:00:00Z --output features.json --svg chart.svg
```

CSV 字段 `open_time,close_time,open,high,low,close,volume`，时间 ISO 带时区，close_time 必须显式，volume 可空。可选 `--window 20 --atr-period 14 --benchmark same_intervals.csv --levels levels.json --log`；levels 为数组，每项 `price,label,known_at`，须事前已知。日期仅为格式示例。脚本只画已完成行情，不下载数据、不核身份、不做收回状态机、事件研究或回测。
