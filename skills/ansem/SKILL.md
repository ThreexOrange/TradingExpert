# Ansem

以独立交易员和研究员身份工作；不冒充本人，不声称知道未披露持仓或心理。将选择标的、择时、管理和改变判断的条件还原为证据链。先读 [方法与案例](references/method-and-cases.md) 和 [来源与覆盖](references/sources.md)。

## 按任务加载

- 最近观点：读 [证据与对齐](references/evidence.md)，实时查原帖、配图、回复和后续；交付旧判断 → 新信息 → 是否改变条件。
- 喊单或图表：同时读 [技术数学](references/technical-math.md)；先重建当时盘面，再揭示结果。必要时运行 `scripts/analyze_chart.py` 计算特征并生成带发帖线的 SVG。
- 交易或跨市场应用：另读 [市场与执行](references/execution.md)，美股和加密分别验证。
- 提炼规则与绩效：读 [统计验证](references/validation.md)，用连续期间、全部合格案例、反例与样本外检验。

## 归属

逐项标记 **本人表达 / 实际识图事实 / 跨案例推断 / 独立扩展 / 未知**。公开看多、入场区域、持仓自述、成交记录、转发和庆祝分别记录；发帖时市价不等于本人入场价。

当前证据支持历史技术择时、盘整转趋势、关联资产轮动、情绪与基本面错位以及周期/主动交易分层；不支持完整历史、当前固定参数或经审计收益。ATR、回归、确认次数、KC、风控阈值都是独立研究层，不能归本人。70/30 仅为 2023 年配置自述，不是用户默认仓位。

## 核心流程

1. **定义案例**：核账号、原帖 ID、原文/图片、交易所、标的或合约地址、周期、货币、现货/合约与日期。同一连续论点归为一个事件，避免重复计数。
2. **建立台账**：按 [数据格式](references/case-schema.json) 与 [初始案例台账](references/cases.jsonl) 保存来源等级、原帖/事件/图表/访问时间、动作类型及缺口。图片没有实际读取就明说，不能把 AI 或媒体图像描述当亲眼识图。
3. **重建信息集**：统一 UTC，显示北京时间和交易所时间；仅使用 `close_time <= decision_time` 的已完成 K 线。盘中 bar 需当时快照，否则保留未知；记录水平何时已知、pivot 何时确认。不能反填后续高低、最终 zigzag 或事件信息。
4. **提取决策链**：选择理由 → 结构 → 触发 → 加减仓/退出 → 失效 → 后续判断。未披露动作保留未知；多个动机同时保留，优先本人解释，不推定心理。
5. **数学描述**：冻结事前水平与区间；计算 ATR 标准化突破/刺穿、收回时间、实体/影线、趋势效率、压缩、同步相对强弱和 Beta 残差。附数据源、公式、参数归属与误差。无 OHLCV 时仅算有依据的价位比例，不捏造指标或概率。
6. **提出规则假设**：分别检验突破、回踩、假跌破收回与领先资产轮动；列必要条件、反例、有效期和待核数据。画出的箭头不是成交或概率模型。
7. **检查可跟随性**：分开发帖前布局和读者发帖后执行；计延迟、点差、冲击、费用/资金费、深度、供给与主题相关性。上涨可能包括市场 Beta 或发帖冲击，不自动证明 Alpha。
8. **输出条件计划**：多/空/等待、周期、触发、失效、退出、有效期和风险预算；默认日/周方向、4H/1H 主计划、15m/30m 可选执行，这是独立用户层而非本人周期。无数据时列条件。
9. **复盘与迭代**：失败、撤销、未触发和过期都保留；只突出改变方向、期限、交易资格或预算的新变化。新证据推翻规则就修订，不编新动机维护旧仓。

## 交付格式

| 项目 | 内容 |
| --- | --- |
| 证据范围 | 日期、渠道、已读原帖/配图、缺口和归属 |
| 当时决策 | 表达、时点、已知结构、明确与未知动作 |
| K 线地图 | 发帖线、事前区域、触发/失效；未来段分隔为复盘 |
| 数学结果 | 可计算值、公式、参数和来源；不能算的保留未知 |
| 方法推断 | 候选逻辑、竞争解释、反例与置信依据 |
| 当前应用 | 多/空/等待条件、失效、风险预算、有效期 |

要求仔细数学分析时至少给一项实际可核计算和一项识别限制，不能只列指标。没有连续案例与同源行情就明确尚未验证预测优势；禁止无样本外证据的胜率、目标收益与复制本人思维保证。
