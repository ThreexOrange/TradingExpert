# Ansem（研究模式）

把 Ansem 的公开判断还原成证据链：他说了什么、当时能看到什么、后来怎么变。交易规则和交易卡不在这里，按 Ansem 方法做计划时改用 [ansem-ta-system](../ansem-ta-system/SKILL.md)。

## 归属

不冒充本人，不声称知道未披露的持仓或心理。每个结论标 **本人表达 / 识图事实 / 跨案例推断 / 独立扩展 / 未知**；规则层沿用 ansem-ta-system 的【A】【A+】【补】。观点、持仓自述、成交记录分开，发帖时市价不是本人入场价。ATR、回归、阈值和风控参数都是独立研究层；目前没有连续喊单全集、可靠成交或经审计收益。

## 按任务加载

- 最近观点：先读 [来源](references/sources.md)，实时查原帖、配图、回复和后续；交付"旧判断 → 新信息 → 条件是否改变"。
- 喊单或图表复盘：读 [研究方法](references/research.md) §1–4 和 [本人方法与案例](references/method-and-cases.md)；先重建当时盘面再揭示结果，需要时运行 `scripts/analyze_chart.py`。
- 入台账：按 [数据格式](references/case-schema.json) 写进 [cases.jsonl](references/cases.jsonl)；同一连续论点归一个 cluster。
- 统计或回测：读 research.md §5–6；4H 量化对照组见 [量化变体 A](references/quant-variant-A.md)，记录用 [模板](assets/manual-review-template.md)。

## 流程

1. **定义案例**：账号、原帖 ID、原文/图片、标的、周期、日期、动作类型。
2. **重建信息集**：统一 UTC，只用当时已收盘的 K 线，冻结事前水平。
3. **决策链**：理由 → 结构 → 触发 → 失效 → 后续；未披露的留未知。
4. **数学描述**：给可核的计算、公式、数据源和误差；无数据不造指标。
5. **复盘**：失败、撤销、未触发都保留；新证据推翻假设就改。

## 交付

| 项目 | 内容 |
| --- | --- |
| 证据范围 | 日期、渠道、已读原帖/配图、缺口 |
| 当时决策 | 表达、时点、已知结构、明确与未知动作 |
| K 线地图 | 发帖线、事前位、触发/失效；未来段单列 |
| 数学结果 | 可核计算和至少一项识别限制 |
| 推断 | 候选逻辑、竞争解释、反例 |

没有连续案例和同源行情时，明确写尚未验证预测优势，不给胜率或收益承诺。
