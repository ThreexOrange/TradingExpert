# Ansem 手动回测记录模板

复制一份表单对应一个候选事件；包括否决/未触发，不只成功交易。所有时间记录 UTC 与北京时间；美股另记纽约当地日期/夏令时。

| 项目 | 填写 |
| --- | --- |
| 事件 ID / 版本 / A 或 B | |
| 市场 / 交易所 / 标的 / 基准 / 周期 | |
| 数据源 / 复权政策 / 时区 / 信号收盘时间 | |
| 观察池冻结时间及当时选入依据 | |
| 叙事 / 催化 / 原始资料发布日期 | |
| 作者案例或独立扫描 / 原帖 URL / 是否已读配图 | |
| 最新已完成日线 / 基准 C、EMA20、EMA50 | |
| RS20 / RS5 / 资产日线 C、EMA20 | |
| U / D / ATR14 / ER20 / CLV / 突破幅度 | |
| 入场前截图 / 信息缺口 | |
| 否决原因 / 取消 / 未触发 / 过期 | |
| 入场决定时间 / 实际可执行时间 / E / 延迟 | |
| S / T / H100 / 初始风险预算 / Q / R0 | |
| 财报或解锁过滤 / 组合限额 / 现金占用 | |
| 每单位手续费、滑点、点差假设及依据 | |
| 出场时间 / 出场价 / 止损、目标、结构或时间退出 | |
| 路径不明 / 跳空 / 停牌 / 剩余未平仓 | |
| 毛损益 / 实际费用 / 净损益 / 净 R | |
| MAE / MFE / 持有 bar 数 / 退出前数据限制 | |
| 规则遵守 / 偏离事实 / 改进假设（留到下一版本） | |

每版本统计：连续期间、全部候选数、合格成交数、平均净 R、胜率、平均盈亏、PF、按时间组合最大回撤、最长连亏、费用敏感性、各市场/板块分组、盈利集中度、留出结果。不得回填未知原始资料；改变规则另编号。
